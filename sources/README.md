# แหล่งอ้างอิงของบทเรียน

Repository นี้เก็บบทเรียนที่เรียบเรียงขึ้นและรายการอ้างอิง ไม่เผยแพร่ไฟล์ lecture เอกสารประกอบ ใบงาน template หรือภาพจากเอกสารต้นฉบับของมหิดล

- [manifest.json](manifest.json) เป็นรายการชื่อเอกสารและบทเรียนที่ใช้อ้างอิง รวม 42 รายการ ไม่ใช่รายการดาวน์โหลด ค่า SHA-256 ใช้ระบุฉบับเอกสารเท่านั้น
- ชื่อเอกสารและเลขหน้าในบทเรียนคงไว้เพื่อให้ตรวจแหล่งที่มาได้ ผู้เรียนควรรับเอกสารต้นฉบับผ่านช่องทางที่ผู้สอนหรือเจ้าของสิทธิ์อนุญาต
- ไฟล์ต้นฉบับถอดออกจากเวอร์ชันปัจจุบันเมื่อ 23 ตุลาคม 2026 ประวัติ commit เดิมไม่ได้ถูกเขียนใหม่ จึงยังอาจมีไฟล์ใน commit เก่า

ไม่ควรเพิ่มต้นฉบับกลับเข้า repository หรือชุดเผยแพร่โดยไม่มีสิทธิ์เผยแพร่ที่ชัดเจน `.gitignore` ป้องกันการเพิ่มไฟล์ในโฟลเดอร์ต้นฉบับและสำเนาดาวน์โหลดเดิมโดยไม่ตั้งใจ
