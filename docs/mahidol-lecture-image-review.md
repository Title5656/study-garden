# ตรวจภาพ lecture ในรายวิชามหิดล

วันที่ตรวจ: 23 ตุลาคม 2026

ตรวจทุกหน้า HTML ของ ITDS241, ITDS261 และ ITDS294 รวมถึงบทเรียน หน้าสอบ และหน้ารวมวิชา พร้อมตรวจการอ้างอิงรูปใน JavaScript และ CSS

| วิชา | ผลตรวจ | การแก้ไข |
|---|---|---|
| ITDS241 Web Technologies and Applications | ไม่พบภาพสไลด์ lecture ที่ฝังในบทเรียน | คงเนื้อหาเดิม |
| ITDS261 Introduction to Software Engineering | พบภาพ lecture 11 ภาพ ในบท 01–11 และภาพแนวทางสวนสัตว์ 3 ภาพในบท 05 | แทนทั้ง 14 จุดด้วยเนื้อหาที่อ่านได้โดยไม่พึ่งภาพ และลบไฟล์ภาพที่เลิกใช้งาน |
| ITDS294 Electronic Commerce | ไม่พบภาพสไลด์ lecture ที่ฝังในบทเรียน | คงเนื้อหาเดิม |

ภาพแนวคิด SVG ที่จัดทำเพิ่ม กิจกรรม แบรนด์ และภาพตกแต่งยังใช้งานตามเดิม เอกสารอ้างอิงต้นทางยังอยู่ในส่วนแหล่งที่มา

## การตรวจสอบ

- `node tools/check-assets.mjs` ตรวจไฟล์และ content hash ของ assets
- `node tools/check-curriculum.mjs` ตรวจบทเรียน Quiz แหล่งที่มา และลิงก์ภายใน
- `node tools/test-learning.mjs` ทดสอบเบราว์เซอร์ที่ 1440/390px รวม 26 บทของมหิดล, สารบัญ, รูปที่เหลือ, Quiz, Flashcards, การบันทึกความคืบหน้า, dark mode และการอ่านเมื่อปิด JavaScript
- ปรับ browser test ของสวนสัตว์ให้ตรวจข้อความแทนการค้นหาภาพที่ถอดออก

การแก้ภาพสไลด์รวมในชุดถอดเอกสารต้นฉบับออกจากเวอร์ชันปัจจุบันของ GitHub และเว็บไซต์ โดยไม่เขียนประวัติ commit ใหม่ตามคำสั่งผู้ใช้
