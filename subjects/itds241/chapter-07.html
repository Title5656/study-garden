ก่อนเริ่มบทนี้ · ต่อจากค่าหนึ่งค่าไปสู่งานหนึ่งชุด

ก่อนเริ่ม ให้ลองอธิบายว่า let price = 100; ผูกชื่อกับค่าอย่างไร หากยังไม่ชัด กลับไปอ่าน ตัวแปรในบท 6 แล้วต่อที่ Object และ Array

คำอธิบายและตัวอย่างสถานการณ์ในบทนี้เรียบเรียงเพิ่มเพื่อช่วยเรียนรู้จากเอกสารรายวิชา ไม่ใช่เฉลยข้อสอบทางการ แหล่งต้นฉบับระบุไว้ท้ายบท

คำศัพท์ที่ใช้ในบทนี้

Function / call
Function คือชุดคำสั่งสำหรับทำงานหนึ่งหน่วย Call คือการเรียกให้ชุดคำสั่งนั้นทำงาน การเขียนนิยามไว้ยังไม่เท่ากับการเรียก
Parameter / argument / return
Parameter คือชื่อช่องรับข้อมูลในนิยามฟังก์ชัน Argument คือค่าจริงที่ส่งเข้ามาตอนเรียก ส่วน return ส่งค่ากลับให้จุดที่เรียกและจบการทำงานครั้งนั้น
Callback / higher-order function
Callback คือฟังก์ชันที่ส่งให้โค้ดอื่นเรียก Higher-order function คือฟังก์ชันที่รับฟังก์ชันหรือคืนฟังก์ชัน ไม่ได้แปลว่าต้องรอเวลาเสมอ
Scope / closure / lifetime
Scope คือบริเวณที่เข้าถึงชื่อได้ Closure คือฟังก์ชันพร้อมการอ้างถึงตัวแปรแวดล้อมที่ประกาศไว้ ส่วน lifetime คือช่วงที่ข้อมูลนั้นยังคงอยู่
Object / class / method / this
Object คือกลุ่มข้อมูลและพฤติกรรม Class คือแบบกำหนดโครงสร้างสำหรับสร้าง object Method คือฟังก์ชันที่เป็นสมาชิก และ this คือค่าบริบทของการเรียก ซึ่งขึ้นกับรูปแบบฟังก์ชันและวิธีเรียก
DOM / node / element / event
DOM คือแบบจำลองเอกสารเป็นต้นไม้ Node คือหน่วยในต้นไม้นั้น Element คือ node ของแท็ก HTML และ event คือเหตุการณ์ที่โปรแกรมรับรู้ เช่น การคลิก
Hoisting / initialization / lexical
Hoisting คือการเตรียม binding ก่อนรันคำสั่ง; initialization คือทำให้ binding มีค่าเริ่มต้นที่อ่านได้ ส่วน lexical หมายถึงยึดตำแหน่งที่เขียนโค้ด เช่น arrow ใช้ this จากบริบทแวดล้อม
Prototype / interface
Prototype คือต้นแบบที่ใช้ค้น property เมื่อ object ไม่มีเอง Interface ในบทนี้หมายถึงชื่อและรูปแบบการเรียกที่ตกลงร่วมกัน ไม่ใช่คำสั่ง interface ของ JavaScript
Synchronous / asynchronous / thread
Synchronous ทำงานในลำดับการเรียกปัจจุบัน ส่วน asynchronous จัดงานให้รับผลภายหลัง Thread คือทางเดินการประมวลผลหนึ่งสาย งานหนักบนสายหลักจึงทำให้ callback ต้องรอ
Attribute / collection
Attribute คือข้อมูลกำกับแท็ก เช่น id และ class ส่วน collection คือชุดสมาชิกที่เลือกจาก DOM; static คือชุดที่ไม่เปลี่ยนสมาชิกตาม DOM ภายหลัง ส่วน live เปลี่ยนตาม DOM

01 · ฟังก์ชันคือหน่วยของงาน

ถ้าร้านค้าต้องคิดราคาหลังลดให้ลูกค้าหลายคน เราจะคัดลอกคำสั่งลบส่วนลดทุกครั้งหรือเก็บวิธีคิดไว้ให้เรียกซ้ำ? Function (ฟังก์ชัน) คือชุดคำสั่งที่รวมเป็นงานหนึ่งหน่วยและเรียกใช้งานได้ ลองตามการส่งค่าจริงเข้าสู่ชื่อรับข้อมูลก่อนดูรูปแบบย่อ

ฟังก์ชันช่วยให้เราเรียกใช้วิธีทำงานเดิมโดยไม่ต้องคัดลอกโค้ด คิดเป็นกล่องที่รับข้อมูล ทำงาน และอาจส่งผลลัพธ์กลับ การแยกฟังก์ชันตามหน้าที่ทำให้อ่าน ทดสอบ และแก้ไขได้ตรงจุด

Parameter คือชื่อในนิยาม เช่น price; argument คือค่าตอนเรียก เช่น 100 ส่วน return ส่งค่ากลับและจบการทำงานของฟังก์ชันทันที ถ้าไม่ return ค่า ผลลัพธ์คือ undefined

ตัวอย่างสมมติ: ราคาเต็ม 100 ลด 20 เหลือเท่าไร

function calculatePrice(price, discount) {
  return price - discount; // ส่งผลกลับไปยังผู้เรียก
}
const amountToPay = calculatePrice(100, 20);
console.log(amountToPay);

ผลใน Console: 80

  1. นิยาม calculatePrice บอกวิธีทำงาน แต่ยังไม่ลบตัวเลข
  2. เมื่อพบ calculatePrice(100, 20) ค่าจริง 100 และ 20 เป็น argument ที่จับคู่กับ parameter price และ discount ตามลำดับ
  3. ภายในฟังก์ชัน price - discount จึงเป็น 100 - 20 ได้ 80
  4. return ส่ง 80 กลับมาเป็นค่าของการเรียก และจบการทำงานครั้งนี้ amountToPay จึงเก็บ 80
  5. console.log แสดง 80 ใน Console การ return เพียงอย่างเดียวไม่แสดงข้อความบนหน้าเว็บ
ลองเปลี่ยนส่วนลดเป็น 0 แล้วทำนายผลก่อนรัน

ได้ 100 เพราะ 100 - 0 = 100 ถ้าสลับ argument เป็น calculatePrice(20, 100) จะได้ -80 เพราะจับคู่ตามตำแหน่ง ไม่ได้เดาจากความหมายของตัวเลข

ข้อผิดพลาดที่พบบ่อย: เขียน console.log ภายในฟังก์ชันแล้วคิดว่าเท่ากับ return ไม่จริง การพิมพ์ผลกับการส่งค่ากลับเป็นคนละงาน หากไม่มี return ค่า ผู้เรียกจะได้รับ undefined

ต่อยอด: ค่าตั้งต้นและรูปแบบย่อ

JAVASCRIPT
function finalPrice(price, discount = 0) {
  return price - discount;
}
finalPrice(100, 20); // 80
finalPrice(100);     // 100: ใช้ default
const double = n => n * 2;
const add = (a, b) => {
  return a + b;      // มี { } จึงต้องเขียน return
};
รูปแบบ จุดเด่น ข้อควรระวัง
Function declaration function sum() { … } มีชื่อชัด declaration ถูก hoist จึงเรียกก่อนตำแหน่งนิยามได้ใน scope ที่เกี่ยวข้อง
Function expression เก็บเป็นค่า เช่น const sum = function() { … } ใช้ก่อน initialization ของ const ไม่ได้
Arrow function สั้น เหมาะกับ callback ไม่มี this ของตัวเอง และใช้ new ไม่ได้
Arrow ไม่ได้แทน function ได้ทุกกรณี: this มาจาก lexical environment รอบตัว ถ้าต้องการ method ที่ this เปลี่ยนตาม object ผู้เรียก ให้เลือก method syntax หรือ function ให้เหมาะ

คำถาม · const f = x => { x * 2; }; f(3) ได้ 6 หรือไม่?

ไม่ได้ ได้ undefined เพราะมีบล็อก { } แต่ไม่มี return แก้เป็น x => x * 2 หรือ x => { return x * 2; }

02 · ส่งฟังก์ชันให้ฟังก์ชัน

ถ้าเรามีขั้นตอน “ทำงานกับตัวเลขทุกตัว” อยู่แล้ว จะเปลี่ยนจากคูณสองเป็นยกกำลังสองโดยไม่เขียน loop ใหม่ได้อย่างไร? ส่งวิธีคำนวณเข้าไปเป็นข้อมูล เหมือนส่งสูตรให้เครื่องคิดเลขใช้ทีละรายการ คำว่า callback บอกความสัมพันธ์ว่าใครจะเรียกฟังก์ชันนั้น ไม่ได้บอกว่าจะเรียกทันทีหรือรอภายหลัง

ใน JavaScript ฟังก์ชันเป็น first-class value: เก็บในตัวแปร ใส่ใน array ส่งเป็น argument และคืนจากฟังก์ชันอื่นได้ ด้วยเหตุนี้เราจึงแยก “ขั้นตอนทั่วไป” ออกจาก “วิธีทำงานเฉพาะ” ได้

ฟังก์ชันที่รับหรือคืนฟังก์ชันเรียกว่า higher-order function ส่วนฟังก์ชันที่เราส่งเข้าไปเพื่อให้ถูกเรียกต่อเรียกว่า callback สองคำนี้มองคนละฝั่งของความสัมพันธ์เดียวกัน

JAVASCRIPT
function applyTo(value, operation) { // higher-order function
  return operation(value);
}
const square = n => n * n;
applyTo(4, square);                  // 16; square คือ callback
[1, 2, 3].map(square);              // [1, 4, 9]
setTimeout(() => console.log("พักสายตา"), 1000);

Synchronous callback

map เรียก callback ระหว่างการทำงานของมัน และคืน array หลังประมวลผลครบ

Asynchronous callback

setTimeout ลงทะเบียน callback ให้ทำภายหลัง เวลา 1000 ms ไม่รับประกันว่าจะเรียกตรงเป๊ะ หากงานอื่นยังครอง thread

คำถาม · setTimeout(sayHi, 1000) ต่างจาก setTimeout(sayHi(), 1000) อย่างไร?

แบบแรกส่งตัวฟังก์ชันให้เรียกภายหลัง แบบที่สองเรียก sayHi ทันที แล้วนำค่าที่คืนไปส่งต่อ ซึ่งมักไม่ใช่ callback ที่ต้องการ

ตาม applyTo(4, square): value รับ 4 ส่วน operation รับตัวฟังก์ชัน square จากนั้น operation(value) จึงเรียก square ด้วย 4 ได้ 16 แล้ว return ต่อกลับผู้เรียก ถ้าเขียน square(4) ตรง argument จะส่งเลข 16 แทนตัวฟังก์ชัน การพยายามเรียก 16 เป็นฟังก์ชันจึงผิด

function applyTo(value, operation) { return operation(value); }
const square = n => n * n;
console.log(applyTo(4, square));
ทุก callback ทำงานแบบ asynchronous หรือไม่?

ไม่ใช่ map เรียก callback ระหว่างประมวลผลและคืนผลเมื่อทำครบ ส่วน setTimeout วางงานไว้ทำภายหลัง คำว่า callback บอกว่าฟังก์ชันถูกส่งไปให้เรียกต่อ ไม่ได้กำหนดเวลา

03 · Scope และ Closure

ถ้ามีชื่อ count อยู่สองแห่ง คอมพิวเตอร์จะอ่านตัวไหน และทำไมปุ่มนับยังจำจำนวนได้หลังฟังก์ชันสร้างปุ่มทำงานจบ? ให้แยก “มองเห็นชื่อจากจุดนี้หรือไม่” ออกจาก “ข้อมูลยังถูกอ้างถึงอยู่หรือไม่” Environment ในคำอธิบายนี้คือบริบทที่ผูกชื่อตัวแปรกับค่า Module คือไฟล์หน่วยโค้ดที่ประกาศแบ่งปันชื่อด้วย export และรับด้วย import ส่วน classic script คือสคริปต์ทั่วไปที่ไม่ได้ประกาศ type="module"

Scope ตอบว่าอ่านตัวแปรจากจุดไหนได้ ส่วน lifetime ตอบว่าข้อมูลยังมีชีวิตอยู่นานเท่าไร JavaScript ใช้ lexical scope คือดูจากตำแหน่งที่เขียนฟังก์ชัน ไม่ใช่ที่ที่เรียกมัน

ขอบเขต ลักษณะ ตัวอย่าง
Global เข้าถึงจากโค้ดในขอบเขตรวมได้ ตัวแปรระดับบนของ classic script
Module แต่ละ module มี scope ของตัวเอง export/import ใช้แชร์ชื่ออย่างชัดเจน
Function ตัวแปรภายในฟังก์ชัน var ยึด function scope ไม่ใช่ block
Block จำกัดใน { … } let และ const ใน if หรือ for

เมื่อมีชื่อซ้ำ การค้นหาจะเลือกตัวแปรใน scope ใกล้ที่สุดก่อน (shadowing) ข้อสำคัญคือ var ก็อยู่ในระบบ lexical scope แต่ไม่สร้างขอบเขตใหม่ตาม block แบบ let/const

Closure: ฟังก์ชันที่พกทางเข้าถึงความจำเดิม

เมื่อคืนฟังก์ชันที่ใช้ตัวแปรภายนอกออกมา ฟังก์ชันนั้นยังอ้างอิง environment เดิมได้ จึงไม่ถูกตัดขาดเพียงเพราะฟังก์ชันภายนอกจบแล้ว แต่ไม่ได้แปลว่าตัวแปร local ทุกตัวจะถูกเก็บตลอดไป

JAVASCRIPT
function makeCounter() {
  let count = 0;
  return () => ++count; // ปิดครอบ environment ที่มี count
}
const counterA = makeCounter();
const counterB = makeCounter();
counterA(); // 1
counterA(); // 2
counterB(); // 1: อีก environment หนึ่ง

Closure lab · สองกล่องความจำ

ลองเพิ่ม A หลายครั้ง แล้วดูว่า B เปลี่ยนตามหรือไม่

environment A 0
environment B 0

makeCounter() ถูกเรียกสองครั้ง จึงมี count สองชุดแยกกัน

คำถาม · ถ้าเขียน const c = counterA; แล้วเรียก c() จะมี count ใหม่ไหม?

ไม่มี เพราะเพียงคัดลอกการอ้างอิงฟังก์ชันเดิม c และ counterA จึงใช้ environment เดียวกัน ต้องเรียก makeCounter() ใหม่จึงได้อีกชุด

ลองกิจกรรมตัวนับ: กด A สองครั้งแล้ว B หนึ่งครั้ง ควรเห็น A = 2, B = 1 เพราะการเรียก makeCounter แต่ละครั้งสร้าง count คนละตัว กดรีเซ็ตเพื่อสร้างสองชุดใหม่ ไม่ใช่แค่เปลี่ยนข้อความบนหน้าจอ ถ้าไม่ได้เปิด JavaScript ให้ตามโค้ดนี้ ผลเดียวกันแสดงใน Console

function makeCounter() {
  let count = 0;
  return () => ++count;
}
const a = makeCounter();
const b = makeCounter();
console.log(a());
console.log(a());
console.log(b());
ถ้า const c = a; แล้วเรียก c() ต่อจากตัวอย่าง จะได้ 1 หรือ 3?

ได้ 3 เพราะ c อ้างฟังก์ชันเดียวกับ a ไม่ได้เรียก makeCounter เพื่อสร้าง environment ใหม่ นี่เชื่อมกับการอ้างอิง object ในบท 6

04 · Class, Object และการสืบทอด

ถ้าระบบมีผู้เรียนหลายคน แต่ละคนต้องมีชื่อของตัวเองและใช้วิธีแนะนำตัวแบบเดียวกัน เราควรแยกข้อมูลของแต่ละคนออกจากแบบแผนร่วม OOP (Object-oriented programming) คือการจัดโปรแกรมด้วย object ที่รวมข้อมูลกับพฤติกรรม Class คือแบบแผนการสร้าง object; instance คือ object ที่สร้างจากแบบแผนนั้น; constructor คือขั้นตอนตั้งข้อมูลเมื่อสร้าง และ this คือค่าตัวรับที่วิธีเรียกฟังก์ชันกำหนดให้ ใน method ที่เรียกผ่าน instance ปกติจะหมายถึง instance นั้น

OOP รวมข้อมูล (properties) และงานที่ทำกับข้อมูล (methods) ให้อยู่ใน object เดียวกัน Class คือแบบแผน ส่วน instance คือ object ที่สร้างขึ้นจริง เช่น แบบแผนบัตรนักเรียน กับบัตรของแต่ละคน

Constructor function ใช้ new และกำหนดข้อมูลผ่าน this ได้ ส่วน class เป็นรูปแบบที่ช่วยจัดโค้ดให้ชัดขึ้น โดย JavaScript ยังคงมีระบบ prototype เป็นพื้นฐาน

JAVASCRIPT
function Student(name) { // constructor function
  this.name = name;
}
const mint = new Student("Mint");

class Learner {
  constructor(name) { this.name = name; }
  introduce() { return `ฉันชื่อ ${this.name}`; }
}
class WebLearner extends Learner {
  constructor(name, topic) {
    super(name); // เรียก constructor แม่ก่อนใช้ this
    this.topic = topic;
  }
  introduce() { // override: ชื่อ method เดิม แต่พฤติกรรมต่าง
    return `${super.introduce()} กำลังเรียน ${this.topic}`;
  }
}
const learner = new WebLearner("Mint", "DOM");
console.log(learner.introduce()); // ฉันชื่อ Mint กำลังเรียน DOM
class Learnerextends → WebLearnernew → learnerintroduce() → ข้อความ
แนวคิด ความหมาย ในตัวอย่าง
Instantiation สร้าง object จริงจากแบบแผน new WebLearner(...)
Inheritance รับพฤติกรรมจากต้นแบบแม่ extends Learner
Override กำหนด method ของลูกทับพฤติกรรมที่สืบทอด introduce() ใน WebLearner
Polymorphism เรียก interface เดียวกันแต่ผลตามชนิด object Learner กับ WebLearner ตอบ introduce() ต่างกัน

อ่าน property ที่ไม่มีจะได้ undefined แต่เรียก method ที่ไม่มีจะเกิด TypeError การเพิ่ม property ภายหลังทำได้กับ object ปกติที่ยังขยายได้ แต่ควรออกแบบข้อมูลให้สม่ำเสมอเพื่ออ่านโค้ดง่าย

อ่านตัวอย่าง WebLearner ตามลำดับ: new สร้าง instance; constructor ของลูกเรียก super(name) ให้แม่ตั้งชื่อ; ลูกเพิ่ม topic; เมื่อเรียก introduce จะเลือก method ของลูกที่ override หรือกำหนดพฤติกรรมชื่อเดิมใหม่; super.introduce() อ่านวิธีของแม่มาประกอบข้อความ Prototype คือต้นแบบที่ใช้ค้น property เมื่อ object ไม่มีเอง ส่วน interface ในที่นี้หมายถึงชื่อและรูปแบบการเรียกที่ตกลงร่วมกัน ไม่ใช่ syntax interface ของ JavaScript

สร้างผู้เรียนสองคนแล้วเปลี่ยนชื่อคนแรก ชื่อคนที่สองต้องเปลี่ยนตามหรือไม่?

ไม่จำเป็น และในตัวอย่าง class นี้ไม่เปลี่ยน เพราะ this.name ถูกกำหนดบน instance แต่ละตัว ต่างจากกำหนดตัวแปรสองชื่อให้อ้าง instance เดียวกัน การสืบทอด method ไม่ได้แปลว่า instance ใช้ข้อมูลทุกช่องร่วมกัน

05 · DOM คือหน้าเว็บในรูปต้นไม้

ถ้าจะเพิ่มหัวข้อใหม่โดยไม่โหลดหน้าอีกครั้ง โปรแกรมต้องหาจุดที่จะใส่ข้อมูลให้พบก่อน DOM (Document Object Model) คือแบบจำลองเอกสารที่เบราว์เซอร์สร้างเป็นต้นไม้ Node คือจุดหนึ่งในต้นไม้; element คือ node ที่แทนแท็ก HTML; parent/child คือแม่/ลูก, sibling คือพี่น้อง และ descendant คือลูกหลาน ส่วน selector คือรูปแบบระบุ element เช่น #topics หมายถึง element ที่มี id เป็น topics

เบราว์เซอร์แปลง HTML เป็นต้นไม้ของ node โดย document เป็นจุดเริ่มต้น Element อย่าง h1 หรือ p มี text node เป็นลูก Node ที่มี parent เดียวกันเป็น siblings ส่วน descendant อยู่ลึกลงไปได้หลายระดับ

Attribute อยู่กับ element แต่ไม่ใช่ child ในต้นไม้แบบ text node; และ childNodes รวม text/comment ด้วย ต่างจาก children ที่มีเฉพาะ element

คำสั่ง ผลลัพธ์ การเปลี่ยนตาม DOM
getElementById("id") Element หรือ null เลือก element เดียว
querySelector(".item") Element แรกหรือ null ใช้ CSS selector
querySelectorAll(".item") NodeList static: ชุดสมาชิกไม่เปลี่ยนตามการเพิ่ม/ลบภายหลัง
getElementsByClassName("item") HTMLCollection live: ชุดสมาชิกอัปเดตตาม DOM
getElementsByTagName("li") HTMLCollection live เช่นกัน

NodeList และ HTMLCollection ไม่ใช่ Array โดยตรง ถ้าต้องการใช้ map หรือ filter ให้แปลงด้วย Array.from(collection) ก่อน ส่วน querySelectorAll รองรับ forEach ได้

JAVASCRIPT

ตัวอย่างครบชุด: บันทึกเป็นไฟล์ .html แล้วเปิดในเบราว์เซอร์ได้ ไม่ต้องสร้าง element เพิ่มเอง

<!doctype html>
<html lang="th"><meta charset="utf-8"><title>ทดลอง DOM</title>
<ul id="topics"></ul>
<p id="result"></p>
<script>
const list = document.querySelector("#topics");
const item = document.createElement("li");
item.textContent = "อ่าน DOM";
list.appendChild(item);
item.setAttribute("class", "done");
// ตอนนี้มีลูกหนึ่งตัว ลองใส่ comment หน้าบรรทัดถัดไปเพื่อดูรายการ
list.removeChild(item);
document.querySelector("#result").textContent = "ลูกที่เหลือ: " + list.children.length;
</script></html>

รายการนี้เป็น DOM จริง ลองเพิ่ม แก้ไข และลบ node

textContent หรือ innerHTML?

textContent ใส่ข้อความตรง ๆ ส่วน innerHTML แปลข้อความเป็น HTML markup ถ้าข้อมูลมาจากผู้ใช้และต้องการเพียงข้อความ ให้ใช้ textContent เพื่อไม่เปิดช่องให้แทรก markup/script ที่ไม่ต้องการ การใช้ document.write() หลังโหลดหน้าแล้วอาจแทนเอกสารทั้งหน้า จึงไม่เหมาะกับการอัปเดต UI แบบนี้

ตัวอย่างครบชุดวาง <ul id="topics"></ul> ไว้ก่อน script เพื่อให้โค้ดเลือกพบ ถ้าเลือกไม่พบจะได้ null และเรียก appendChild ต่อไม่ได้ ใน playground นี้รายการจริงใช้ id dom-list ส่วน #topics ที่แสดงเป็นชื่อในภาพสอน ลองเพิ่ม “อ่าน DOM” จะได้ลูกเพิ่มหนึ่งตัว แก้ตัวแรกเปลี่ยนข้อความแต่จำนวนลูกไม่เปลี่ยน ลบตัวท้ายลดจำนวนลงหนึ่ง และเริ่มใหม่คืนรายการตั้งต้น

ตั้ง item.textContent = "<b>สวัสดี</b>" จะได้ตัวหนาหรือข้อความแท็ก?

ได้ข้อความแท็กตามตัวอักษร เพราะ textContent ไม่แปลเป็น HTML นี่เหมาะกับข้อความที่ผู้ใช้กรอก ส่วน innerHTML จะตีความ markup จึงต้องคำนึงถึงความน่าเชื่อถือของข้อมูล

06 · Event เชื่อมการกระทำกับโค้ด

ปุ่มไม่ควรเรียกฟังก์ชันตรวจคะแนนทันทีที่เราเปิดหน้า แต่ควรรอให้ผู้ใช้กดก่อน เราจึงลงทะเบียน listener หรือฟังก์ชันผู้รับเหตุการณ์ไว้ คำว่า register ในบริบทนี้แปลว่าบอกเบราว์เซอร์ว่าเมื่อเกิดเหตุการณ์ชนิดนี้ให้เรียกฟังก์ชันใด โดยส่ง object ที่อธิบายเหตุการณ์ให้ด้วย

Event คือสัญญาณที่เกิดขึ้น เช่น click, input, change, keydown หรือ submit เราลงทะเบียน listener ไว้ก่อน แล้วให้ browser เรียก callback เมื่อเหตุการณ์มาถึง

JAVASCRIPT

ตัวอย่างครบชุด: บันทึกเป็นไฟล์ .html แล้วเปิดในเบราว์เซอร์ได้ ไม่ต้องสร้าง element เพิ่มเอง

<!doctype html>
<html lang="th"><meta charset="utf-8"><title>ทดลอง Event</title>
<button id="check">ตรวจ</button><p id="result">ยังไม่กด</p>
<script>
const button = document.querySelector("#check");
function handleClick(event) {
  document.querySelector("#result").textContent = "รับเหตุการณ์: " + event.type;
}
button.addEventListener("click", handleClick); // ส่งฟังก์ชัน ไม่เรียกตอนลงทะเบียน
</script></html>
Event ใช้เมื่อ จุดที่มักสับสน
click ปุ่มถูกกด ใช้ได้กับการเปิดใช้งานปุ่มด้วย keyboard ด้วย
input ค่าช่องกรอกเปลี่ยนระหว่างพิมพ์ เหมาะกับ preview ทันที
change ผู้ใช้ยืนยันการเปลี่ยนค่า สำหรับ text input มักเกิดเมื่อเปลี่ยนแล้วออกจากช่อง
keydown / keyup กด / ปล่อยปุ่ม keyboard ใช้ event.key ตรวจปุ่ม; keypress เป็น API เก่า
submit ส่งฟอร์ม event.preventDefault() หยุดการส่งตามพฤติกรรมปกติ
load ทรัพยากรโหลดเสร็จ DOMContentLoaded คือ HTML parse เสร็จ ไม่ต้องรอรูปทั้งหมด

JAVASCRIPT

ตัวอย่างครบชุด: บันทึกเป็นไฟล์ .html แล้วเปิดในเบราว์เซอร์ได้ ไม่ต้องสร้าง element เพิ่มเอง

<!doctype html>
<html lang="th"><meta charset="utf-8"><title>บวกสองจำนวน</title>
<label>จำนวนแรก <input id="first" value="12"></label>
<label>จำนวนที่สอง <input id="second" value="3"></label>
<button id="add">บวก</button><p id="result">รอคำนวณ</p>
<script>
function addInputs() {
  const first = document.querySelector("#first").value.trim();
  const second = document.querySelector("#second").value.trim();
  const a = Number(first);
  const b = Number(second);
  if (!first || !second || !Number.isFinite(a) || !Number.isFinite(b)) {
    return "กรุณากรอกตัวเลขทั้งสองช่อง";
  }
  return a + b;
}
document.querySelector("#add").addEventListener("click", () => {
  document.querySelector("#result").textContent = addInputs();
});
</script></html>
ภาพรวมทั้งบท: Event เรียก function → function อ่านหรือเปลี่ยน state → ใช้ DOM สะท้อนผลกลับไปยังหน้าเว็บ สิ่งที่เห็นกับข้อมูลที่เก็บควรสอดคล้องกันเสมอ

ตัวอย่างครบชุดใส่ปุ่มและช่องกรอกก่อน script แล้ว โดยปุ่มตรวจใช้ id เป็น check ส่วนตัวอย่าง addInputs ใช้ input ที่ id เป็น first กับ second ตามลำดับ เมื่อกรอก "12" และ "3" ค่า .value เป็นข้อความทั้งคู่ การบวกโดยไม่แปลงจะได้ "123" แต่ Number แปลงให้คำนวณได้ 15 โค้ดตรวจข้อความว่างก่อน เพราะ Number("") ได้ 0 ซึ่งอาจกลบข้อมูลที่ผู้ใช้ลืมกรอก

ปุ่มมีข้อความอยู่ใน span ภายใน เมื่อกด span event.target กับ event.currentTarget ต่างกันอย่างไร?

target คือ element ต้นทางที่ถูกกด เช่น span ส่วน currentTarget คือ element ที่ listener ปัจจุบันผูกอยู่ เช่น button จึงไม่ควรสมมติว่า target เป็นปุ่มเสมอ เมื่อใช้ปุ่ม HTML จริง การกด Enter/Space จะใช้พฤติกรรมปุ่มตามปกติได้ด้วย

สรุปบท

ฟังก์ชันแยกงานให้เรียกซ้ำได้ โดยรับ argument ผ่าน parameter และส่งผลกลับด้วย return เมื่อส่งฟังก์ชันเป็นค่า เราสร้าง callback ได้ Closure อธิบายว่าฟังก์ชันยังเข้าถึงตัวแปรจากบริเวณที่ประกาศได้อย่างไร ส่วน class จัดข้อมูลกับพฤติกรรมที่เกี่ยวข้องเข้าด้วยกัน เมื่อนำไปใช้กับ DOM และ event การคลิกหนึ่งครั้งจึงเรียกฟังก์ชันเพื่ออ่านหรือเปลี่ยนโครงสร้างหน้าเว็บได้ บทต่อไปจะต่อยอดเมื่อผลของงานยังไม่พร้อมทันที
