01 · ฟังก์ชันคือหน่วยของงาน

ฟังก์ชันช่วยให้เราเรียกใช้วิธีทำงานเดิมโดยไม่ต้องคัดลอกโค้ด คิดเป็นกล่องที่รับข้อมูล ทำงาน และอาจส่งผลลัพธ์กลับ การแยกฟังก์ชันตามหน้าที่ทำให้อ่าน ทดสอบ และแก้ไขได้ตรงจุด

Parameter คือชื่อในนิยาม เช่น price; argument คือค่าตอนเรียก เช่น 100 ส่วน return ส่งค่ากลับและจบการทำงานของฟังก์ชันทันที ถ้าไม่ return ค่า ผลลัพธ์คือ undefined

JAVASCRIPT
function finalPrice(price, discount = 0) {
  return price - discount;
}
finalPrice(100, 20); // 80
finalPrice(100);     // 100: ใช้ default
const double = n => n * 2;
const add = (a, b) => {
  return a + b;      // มี { } จึงต้องเขียน return
};
รูปแบบ จุดเด่น ข้อควรระวัง
Function declaration function sum() { … } มีชื่อชัด declaration ถูก hoist จึงเรียกก่อนตำแหน่งนิยามได้ใน scope ที่เกี่ยวข้อง
Function expression เก็บเป็นค่า เช่น const sum = function() { … } ใช้ก่อน initialization ของ const ไม่ได้
Arrow function สั้น เหมาะกับ callback ไม่มี this ของตัวเอง และใช้ new ไม่ได้
Arrow ไม่ได้แทน function ได้ทุกกรณี: this มาจาก lexical environment รอบตัว ถ้าต้องการ method ที่ this เปลี่ยนตาม object ผู้เรียก ให้เลือก method syntax หรือ function ให้เหมาะ

คำถาม · const f = x => { x * 2; }; f(3) ได้ 6 หรือไม่?

ไม่ได้ ได้ undefined เพราะมีบล็อก { } แต่ไม่มี return แก้เป็น x => x * 2 หรือ x => { return x * 2; }

02 · ส่งฟังก์ชันให้ฟังก์ชัน

ใน JavaScript ฟังก์ชันเป็น first-class value: เก็บในตัวแปร ใส่ใน array ส่งเป็น argument และคืนจากฟังก์ชันอื่นได้ ด้วยเหตุนี้เราจึงแยก “ขั้นตอนทั่วไป” ออกจาก “วิธีทำงานเฉพาะ” ได้

ฟังก์ชันที่รับหรือคืนฟังก์ชันเรียกว่า higher-order function ส่วนฟังก์ชันที่เราส่งเข้าไปเพื่อให้ถูกเรียกต่อเรียกว่า callback สองคำนี้มองคนละฝั่งของความสัมพันธ์เดียวกัน

JAVASCRIPT
function applyTo(value, operation) { // higher-order function
  return operation(value);
}
const square = n => n * n;
applyTo(4, square);                  // 16; square คือ callback
[1, 2, 3].map(square);              // [1, 4, 9]
setTimeout(() => console.log("พักสายตา"), 1000);

Synchronous callback

map เรียก callback ระหว่างการทำงานของมัน และคืน array หลังประมวลผลครบ

Asynchronous callback

setTimeout ลงทะเบียน callback ให้ทำภายหลัง เวลา 1000 ms ไม่รับประกันว่าจะเรียกตรงเป๊ะ หากงานอื่นยังครอง thread

คำถาม · setTimeout(sayHi, 1000) ต่างจาก setTimeout(sayHi(), 1000) อย่างไร?

แบบแรกส่งตัวฟังก์ชันให้เรียกภายหลัง แบบที่สองเรียก sayHi ทันที แล้วนำค่าที่คืนไปส่งต่อ ซึ่งมักไม่ใช่ callback ที่ต้องการ

03 · Scope และ Closure

Scope ตอบว่าอ่านตัวแปรจากจุดไหนได้ ส่วน lifetime ตอบว่าข้อมูลยังมีชีวิตอยู่นานเท่าไร JavaScript ใช้ lexical scope คือดูจากตำแหน่งที่เขียนฟังก์ชัน ไม่ใช่ที่ที่เรียกมัน

ขอบเขต ลักษณะ ตัวอย่าง
Global เข้าถึงจากโค้ดในขอบเขตรวมได้ ตัวแปรระดับบนของ classic script
Module แต่ละ module มี scope ของตัวเอง export/import ใช้แชร์ชื่ออย่างชัดเจน
Function ตัวแปรภายในฟังก์ชัน var ยึด function scope ไม่ใช่ block
Block จำกัดใน { … } let และ const ใน if หรือ for

เมื่อมีชื่อซ้ำ การค้นหาจะเลือกตัวแปรใน scope ใกล้ที่สุดก่อน (shadowing) ข้อสำคัญคือ var ก็อยู่ในระบบ lexical scope แต่ไม่สร้างขอบเขตใหม่ตาม block แบบ let/const

Closure: ฟังก์ชันที่พกทางเข้าถึงความจำเดิม

เมื่อคืนฟังก์ชันที่ใช้ตัวแปรภายนอกออกมา ฟังก์ชันนั้นยังอ้างอิง environment เดิมได้ จึงไม่ถูกตัดขาดเพียงเพราะฟังก์ชันภายนอกจบแล้ว แต่ไม่ได้แปลว่าตัวแปร local ทุกตัวจะถูกเก็บตลอดไป

JAVASCRIPT
function makeCounter() {
  let count = 0;
  return () => ++count; // ปิดครอบ environment ที่มี count
}
const counterA = makeCounter();
const counterB = makeCounter();
counterA(); // 1
counterA(); // 2
counterB(); // 1: อีก environment หนึ่ง

Closure lab · สองกล่องความจำ

ลองเพิ่ม A หลายครั้ง แล้วดูว่า B เปลี่ยนตามหรือไม่

environment A 0
environment B 0

makeCounter() ถูกเรียกสองครั้ง จึงมี count สองชุดแยกกัน

คำถาม · ถ้าเขียน const c = counterA; แล้วเรียก c() จะมี count ใหม่ไหม?

ไม่มี เพราะเพียงคัดลอกการอ้างอิงฟังก์ชันเดิม c และ counterA จึงใช้ environment เดียวกัน ต้องเรียก makeCounter() ใหม่จึงได้อีกชุด

04 · Class, Object และการสืบทอด

OOP รวมข้อมูล (properties) และงานที่ทำกับข้อมูล (methods) ให้อยู่ใน object เดียวกัน Class คือแบบแผน ส่วน instance คือ object ที่สร้างขึ้นจริง เช่น แบบแผนบัตรนักเรียน กับบัตรของแต่ละคน

Constructor function ใช้ new และกำหนดข้อมูลผ่าน this ได้ ส่วน class เป็นรูปแบบที่ช่วยจัดโค้ดให้ชัดขึ้น โดย JavaScript ยังคงมีระบบ prototype เป็นพื้นฐาน

JAVASCRIPT
function Student(name) { // constructor function
  this.name = name;
}
const mint = new Student("Mint");

class Learner {
  constructor(name) { this.name = name; }
  introduce() { return `ฉันชื่อ ${this.name}`; }
}
class WebLearner extends Learner {
  constructor(name, topic) {
    super(name); // เรียก constructor แม่ก่อนใช้ this
    this.topic = topic;
  }
  introduce() { // override: ชื่อ method เดิม แต่พฤติกรรมต่าง
    return `${super.introduce()} กำลังเรียน ${this.topic}`;
  }
}
const learner = new WebLearner("Mint", "DOM");
console.log(learner.introduce()); // ฉันชื่อ Mint กำลังเรียน DOM
class Learnerextends → WebLearnernew → learnerintroduce() → ข้อความ
แนวคิด ความหมาย ในตัวอย่าง
Instantiation สร้าง object จริงจากแบบแผน new WebLearner(...)
Inheritance รับพฤติกรรมจากต้นแบบแม่ extends Learner
Override กำหนด method ของลูกทับพฤติกรรมที่สืบทอด introduce() ใน WebLearner
Polymorphism เรียก interface เดียวกันแต่ผลตามชนิด object Learner กับ WebLearner ตอบ introduce() ต่างกัน

อ่าน property ที่ไม่มีจะได้ undefined แต่เรียก method ที่ไม่มีจะเกิด TypeError การเพิ่ม property ภายหลังทำได้กับ object ปกติที่ยังขยายได้ แต่ควรออกแบบข้อมูลให้สม่ำเสมอเพื่ออ่านโค้ดง่าย

05 · DOM คือหน้าเว็บในรูปต้นไม้

เบราว์เซอร์แปลง HTML เป็นต้นไม้ของ node โดย document เป็นจุดเริ่มต้น Element อย่าง h1 หรือ p มี text node เป็นลูก Node ที่มี parent เดียวกันเป็น siblings ส่วน descendant อยู่ลึกลงไปได้หลายระดับ

Attribute อยู่กับ element แต่ไม่ใช่ child ในต้นไม้แบบ text node; และ childNodes รวม text/comment ด้วย ต่างจาก children ที่มีเฉพาะ element

คำสั่ง ผลลัพธ์ การเปลี่ยนตาม DOM
getElementById("id") Element หรือ null เลือก element เดียว
querySelector(".item") Element แรกหรือ null ใช้ CSS selector
querySelectorAll(".item") NodeList static: ชุดสมาชิกไม่เปลี่ยนตามการเพิ่ม/ลบภายหลัง
getElementsByClassName("item") HTMLCollection live: ชุดสมาชิกอัปเดตตาม DOM
getElementsByTagName("li") HTMLCollection live เช่นกัน

NodeList และ HTMLCollection ไม่ใช่ Array โดยตรง ถ้าต้องการใช้ map หรือ filter ให้แปลงด้วย Array.from(collection) ก่อน ส่วน querySelectorAll รองรับ forEach ได้

JAVASCRIPT
const list = document.querySelector("#topics");
const item = document.createElement("li");
item.textContent = "อ่าน DOM";      // ใส่เป็นข้อความ
list.appendChild(item);             // แนบเข้าเอกสาร
item.setAttribute("class", "done"); // กำหนด attribute
list.removeChild(item);             // ลบ node ลูกนั้น

textContent หรือ innerHTML?

textContent ใส่ข้อความตรง ๆ ส่วน innerHTML แปลข้อความเป็น HTML markup ถ้าข้อมูลมาจากผู้ใช้และต้องการเพียงข้อความ ให้ใช้ textContent เพื่อไม่เปิดช่องให้แทรก markup/script ที่ไม่ต้องการ การใช้ document.write() หลังโหลดหน้าแล้วอาจแทนเอกสารทั้งหน้า จึงไม่เหมาะกับการอัปเดต UI แบบนี้

06 · Event เชื่อมการกระทำกับโค้ด

Event คือสัญญาณที่เกิดขึ้น เช่น click, input, change, keydown หรือ submit เราลงทะเบียน listener ไว้ก่อน แล้วให้ browser เรียก callback เมื่อเหตุการณ์มาถึง

JAVASCRIPT
const button = document.querySelector("#check");
function handleClick(event) {
  console.log(event.target); // element ต้นทางของเหตุการณ์
}
button.addEventListener("click", handleClick);
// ไม่เขียน handleClick() เพราะจะเรียกทันที
Event ใช้เมื่อ จุดที่มักสับสน
click ปุ่มถูกกด ใช้ได้กับการเปิดใช้งานปุ่มด้วย keyboard ด้วย
input ค่าช่องกรอกเปลี่ยนระหว่างพิมพ์ เหมาะกับ preview ทันที
change ผู้ใช้ยืนยันการเปลี่ยนค่า สำหรับ text input มักเกิดเมื่อเปลี่ยนแล้วออกจากช่อง
keydown / keyup กด / ปล่อยปุ่ม keyboard ใช้ event.key ตรวจปุ่ม; keypress เป็น API เก่า
submit ส่งฟอร์ม event.preventDefault() หยุดการส่งตามพฤติกรรมปกติ
load ทรัพยากรโหลดเสร็จ DOMContentLoaded คือ HTML parse เสร็จ ไม่ต้องรอรูปทั้งหมด

ช่อง input ให้ string แม้หน้าตาดูเป็นตัวเลข

JAVASCRIPT
function addInputs() {
  const first = document.querySelector("#first").value.trim();
  const second = document.querySelector("#second").value.trim();
  const a = Number(first);
  const b = Number(second);
  if (!first || !second || !Number.isFinite(a) || !Number.isFinite(b)) {
    return "กรุณากรอกตัวเลขทั้งสองช่อง";
  }
  return a + b;
}
ภาพรวมทั้งบท: Event เรียก function → function อ่านหรือเปลี่ยน state → ใช้ DOM สะท้อนผลกลับไปยังหน้าเว็บ สิ่งที่เห็นกับข้อมูลที่เก็บควรสอดคล้องกันเสมอ
