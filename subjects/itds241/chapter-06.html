01 · JavaScript อยู่ตรงไหน?

นึกถึงเว็บเป็นโต๊ะอ่านหนังสือ: HTML บอกว่ามีอะไรอยู่บนโต๊ะ CSS จัดให้สวยและอ่านง่าย ส่วน JavaScript ทำให้สิ่งบนโต๊ะตอบสนอง เช่น กดเปิดเฉลยแล้วเห็นคำตอบ หรือเลือกคำตอบแล้วได้คะแนน

เบราว์เซอร์มี JavaScript engine สำหรับรันภาษา และมี Web API อย่าง DOM ให้โค้ดจัดการหน้าเว็บได้ ตัวภาษาไม่ได้เท่ากับ DOM และ JavaScript ก็ทำงานนอกเบราว์เซอร์ได้ด้วย

ส่วน หน้าที่ ตัวอย่างในเว็บนี้
HTML โครงสร้างและเนื้อหา หัวข้อบทเรียนกับปุ่ม Quiz
CSS รูปแบบการแสดงผล สี ฟอนต์ และเลย์เอาต์มือถือ
JavaScript ข้อมูลและพฤติกรรม ตรวจคำตอบและพลิก Flashcard
JAVASCRIPT
<!-- เรียกไฟล์ภายนอก และรอให้ HTML ถูก parse ก่อนทำงาน -->
<script defer src="assets/app.js"></script>

เขียนโค้ดระหว่างแท็ก <script> หรือแยกไฟล์ .js ก็ได้ โดยในไฟล์ .js ไม่ต้องใส่แท็ก script อีก ใช้ console.log() ตรวจค่าระหว่างพัฒนา ส่วนข้อความให้ผู้อ่านเห็นต้องอัปเดต DOM

เป้าหมายบทนี้: อ่านโค้ดแล้วบอกได้ว่า “ค่าอะไรเปลี่ยน” และ “บรรทัดถัดไปคืออะไร”

02 · ตัวแปรและชนิดข้อมูล

ตัวแปรคือชื่อที่เราใช้เรียกค่า ประกาศ คือสร้างชื่อ กำหนดค่า คือผูกชื่อกับค่า และ กำหนดค่าเริ่มต้น คือทำทั้งสองอย่างพร้อมกัน เครื่องหมาย = จึงไม่ใช่การถามว่าเท่ากันหรือไม่

JAVASCRIPT
let points;             // ประกาศ: ค่าเริ่มต้นเป็น undefined
points = 10;            // กำหนดค่า
points += 5;            // ตอนนี้ 15
const course = "ITDS241";
console.log(points);    // 15
คำสั่ง ขอบเขต กำหนดใหม่ / ประกาศซ้ำใน scope เดิม
var function หรือ global ได้ / ได้
let block { … } ได้ / ไม่ได้
const block { … } ไม่ได้ / ไม่ได้

เริ่มด้วย const เมื่อไม่ต้องเปลี่ยน binding และใช้ let เมื่อจะกำหนดค่าใหม่ ชื่อตัวแปรแยกตัวพิมพ์เล็ก–ใหญ่ เริ่มด้วยตัวอักษร _ หรือ $ ได้ แต่ห้ามเริ่มด้วยเลขหรือใช้คำสงวนอย่าง class

ชนิดข้อมูล ตัวอย่าง จำอย่างไร
Number 42, 3.14, NaN จำนวนทั่วไปและทศนิยมแบบ floating point
String "hello" ข้อความ
Boolean true, false ผลตัดสินใจ
Undefined let x; ยังไม่ได้กำหนดค่า
Null let selected = null ว่างโดยตั้งใจ
Object { name: "Mint" }, [1, 2] ข้อมูลเป็นกลุ่มหรือโครงสร้าง
BigInt / Symbol 42n / Symbol("id") ชนิด primitive เพิ่มเติมของ JavaScript สมัยใหม่

JavaScript เป็น dynamically typed: ชนิดผูกกับค่า ไม่ใช่ชื่อ เช่น let x = 1; x = "one"; ทำได้ ส่วน typeof null ได้ "object" เพราะพฤติกรรมเก่าของภาษา ไม่ได้หมายความว่า null เป็น object ปกติ

อย่าสับสนช่วง “จำนวนเต็มที่แทนค่าได้อย่างปลอดภัย” ±(253−1) กับช่วงค่าทั้งหมดของ Number ซึ่งกว้างกว่านั้น แต่ไม่ได้แทนจำนวนเต็มทุกค่าได้แม่นยำ

คำถาม · const bag = { count: 1 }; bag.count++; ผิดไหม?

ไม่ผิด count เป็น 2 เพราะแก้ property ของ object เดิม แต่ bag = {} จะผิด เพราะพยายามเปลี่ยน binding ของ const

03 · Object และเครื่องมือพื้นฐาน

Object รวมข้อมูลที่เกี่ยวข้องไว้ด้วยกัน อ่าน property ด้วยจุด หรือใช้วงเล็บเหลี่ยมเมื่อชื่อมาจากตัวแปร การกำหนด object ให้ตัวแปรอีกตัวจะคัดลอก การอ้างอิง ไม่ได้คัดลอกข้อมูลทั้งก้อน

JAVASCRIPT
const student = { name: "Mint", points: 8 };
const friend = student;
friend.points = 10;
console.log(student.points); // 10: อ้างถึง object เดียวกัน
const key = "name";
console.log(student[key]);   // "Mint"
เครื่องมือ ใช้ทำอะไร ตัวอย่างและผล
Number แปลง/ตรวจตัวเลข parseInt("12.5", 10) → 12; parseFloat("12.5") → 12.5
Math คำนวณโดยไม่ต้อง new Math.round(2.6) → 3; Math.pow(2, 3) → 8
Date เก็บจุดเวลาหนึ่ง new Date(); getDate() = วันในเดือน; getDay() = วันในสัปดาห์ 0–6
String จัดการข้อความ "web tech".split(" ") → ["web", "tech"]
Array รายการเริ่ม index ที่ 0 ["a", "b"][0] → "a"; length → 2

Number.isNaN() ใช้ตรวจค่า NaN; Number.isInteger() ตรวจจำนวนเต็ม การแปลงค่าจากช่อง input จำเป็นเพราะ input.value เป็น string โดยปกติ งานทั่วไปใช้ primitive number/string ได้เลย ไม่จำเป็นต้องห่อด้วย new Number() หรือ new String()

เลือก method ของ Array ให้ตรงคำถาม

Method คำถามที่ตอบ เปลี่ยน array เดิมไหม
push / pop เพิ่มท้าย / นำตัวท้ายออก เปลี่ยน
indexOf อยู่ตำแหน่งไหน? ไม่พบคืน −1 ไม่เปลี่ยน
forEach ทำอะไรสักอย่างกับแต่ละตัว ไม่สร้างผลลัพธ์ array; callback อาจแก้ข้อมูลได้
map แต่ละตัวจะกลายเป็นอะไร? คืน array ใหม่
filter เก็บตัวไหนบ้าง? คืน array ใหม่
reduce / reduceRight รวมเป็นผลลัพธ์เดียวจากซ้าย / ขวา ขึ้นกับ callback; ใช้ initial value ให้ชัด
every / some ทุกตัวผ่านไหม / มีอย่างน้อยหนึ่งตัวผ่านไหม คืน Boolean
JAVASCRIPT
const scores = [4, 7, 9];
scores.map(n => n * 2);              // [8, 14, 18]
scores.filter(n => n >= 7);          // [7, 9]
scores.reduce((sum, n) => sum + n, 0); // 20

04 · เปรียบเทียบและตัดสินใจ

เริ่มจากแยก = (กำหนดค่า), == (เทียบแบบอาจแปลงชนิด) และ === (เทียบโดยไม่แปลงชนิด) ออกจากกัน งานทั่วไปนิยม === เพราะผลคาดเดาง่ายกว่า สำหรับ object การเทียบ === ตรวจว่าอ้างอิงก้อนเดียวกันหรือไม่

Expression ผล เหตุผล
"5" + 2 "52" + ต่อข้อความเมื่อมี string
"5" - 2 3 − แปลง string เป็น number เพื่อคำนวณ
"5" == 5 true มีการแปลงชนิด
"5" === 5 false ชนิดต่างกัน
7 % 3 1 เศษจากการหาร
2 + 3 * 4 14 คูณก่อนบวก; วงเล็บเปลี่ยนลำดับได้

ตัวดำเนินการ ++ และ -- เพิ่ม/ลดหนึ่ง โดย x++ ให้ค่าเดิมก่อนเพิ่ม ส่วน ++x เพิ่มก่อนให้ค่า และ +=, *= คือเขียนย่อของการอ่านค่าเดิมแล้วกำหนดค่าใหม่

&& หยุดเมื่อเจอ falsy ส่วน || หยุดเมื่อเจอ truthy และคืน operand ไม่จำเป็นต้องคืน Boolean; ! กลับค่าความจริง ค่าที่พบบ่อยว่า falsy คือ false, 0, "", null, undefined, NaN แต่ [] และ {} เป็น truthy

JAVASCRIPT
const score = 72;
let grade;
if (score >= 80) {
  grade = "A";
} else if (score >= 70) {
  grade = "B";
} else {
  grade = "ทบทวนเพิ่ม";
}
const passed = score >= 50 ? "ผ่าน" : "ทบทวน";
// ตัวอย่างนี้สมมติ score เป็นตัวเลขในช่วง 0–100

if / else if / else เลือกแขนงแรกที่เงื่อนไขเป็นจริง ส่วน ternary condition ? yes : no เหมาะกับการเลือกค่าสั้น ๆ switch เลือก case ที่ตรงแบบ strict equality; หากไม่มี break อาจทำ case ถัดไปต่อ (fall-through) และใช้ default เมื่อไม่พบ case

คำถาม · let x = 2; const y = x++; หลังสองคำสั่งนี้ x และ y เป็นเท่าไร?

x = 3 และ y = 2 เพราะ postfix ให้ค่าเดิมกับ y ก่อนเพิ่ม x

05 · มองเห็น loop ทีละขั้น

Loop คือการกลับมาทำงานเดิมเมื่อเงื่อนไขยังผ่าน ตรวจให้ครบสามอย่าง: เริ่มที่ไหน → ตรวจอะไร → เปลี่ยนค่าอย่างไรให้หยุดได้ การลืมอัปเดตค่าที่ใช้ตรวจอาจทำให้เกิด infinite loop

โครงสร้าง ตรวจเมื่อไร เหมาะกับ
for ก่อนเข้า body แต่ละรอบ มีตัวนับหรือรู้ช่วงที่จะวน
while ก่อนเข้า body แต่ละรอบ ยังไม่รู้จำนวนครั้ง รอเงื่อนไขหรือ sentinel
do…while หลัง body ต้องทำอย่างน้อยหนึ่งครั้ง
JAVASCRIPT
let sum = 0;
for (let i = 1; i <= limit; i++) {
  sum += i;
}
// ลำดับ: เริ่มตัวนับ → ตรวจ → บวก → เพิ่มตัวนับ → กลับไปตรวจ

Loop lab · ผลรวม 1 ถึง n

กดทีละขั้นแล้วสังเกตว่า i เพิ่มเมื่อไร และ sum เปลี่ยนตรงไหน

เริ่มตรวจบวกi++จบ
i 1
sum 0

คำสั่งที่เปลี่ยนทางเดิน

  • break ออกจาก loop ที่ใกล้ที่สุด; continue ข้ามส่วนที่เหลือของรอบนั้น ใน for จะยังไปทำตัวเพิ่มก่อนตรวจรอบใหม่
  • Counter-controlled ใช้ตัวนับ; sentinel-controlled ใช้ค่าพิเศษ เช่น "stop"; loop ซ้อนใช้ตัวนับคนละตัวเพื่อไม่ชนกัน
  • Label เป็นชื่อกำกับ statement ใช้ break ออกไปยังบล็อกที่มีชื่อ หรือ continue ไปยัง loop ที่มีชื่อนั้น ไม่ใช่คำสั่งกระโดดไปที่ใดก็ได้
  • for…in วนชื่อ property ที่ enumerable รวม inherited properties; for…of วนค่าของ iterable เช่น Array (เจาะลึกในบท 8)

คำถาม · ทำไม loop 1 ถึง 3 จบด้วย i = 4 แต่ sum = 6?

หลังบวก 3 แล้ว i++ ทำให้ตัวนับเป็น 4 จากนั้นเงื่อนไข 4 <= 3 เป็น false จึงออกโดยไม่บวก 4 อีก หมายเหตุ: i ที่ประกาศด้วย let ใน for จะอ่านไม่ได้จากนอก loop; lab แสดงสถานะภายในเพื่อการเรียนรู้

06 · เชื่อมทุกอย่างด้วย Tic-tac-toe
