คำอธิบายและตัวอย่างสถานการณ์ในบทนี้เรียบเรียงเพิ่มเพื่อช่วยเรียนรู้จากเอกสารรายวิชา ไม่ใช่เฉลยข้อสอบทางการ แหล่งต้นฉบับระบุไว้ท้ายบท

คำศัพท์ที่ใช้ในบทนี้

Program / statement
โปรแกรมคือชุดคำสั่ง ส่วน statement คือคำสั่งหนึ่งหน่วยที่ให้คอมพิวเตอร์ทำงาน
HTML / CSS / JavaScript
HTML อธิบายโครงสร้างหน้าเว็บ CSS กำหนดรูปลักษณ์ และ JavaScript เป็นภาษาที่ใช้เขียนพฤติกรรมและคำนวณ
Variable / value / binding
Variable คือตัวแปรที่ใช้ชื่ออ้างถึง value หรือค่า ส่วน binding คือการผูกชื่อนั้นกับค่า ไม่ใช่กล่องที่บังคับว่าต้องเก็บเลขตลอดไป
Console / output
Console คือพื้นที่แสดงข้อความสำหรับตรวจการทำงานของโปรแกรม ส่วน output คือผลที่โปรแกรมแสดงออกมา console.log แสดงผลใน Console ไม่ได้เขียนลงหน้าเว็บ
Function / scope / block
Function คือชุดคำสั่งที่เรียกใช้เป็นงานหนึ่งหน่วย Scope คือบริเวณที่เข้าถึงชื่อได้ และ block คือกลุ่มคำสั่งในวงเล็บปีกกา { }
Object / property / array / index
Object รวมข้อมูลที่เกี่ยวข้องเป็นกลุ่ม Property คือข้อมูลแต่ละชื่อใน object Array คือรายการที่เรียงลำดับ และ index คือตำแหน่งของสมาชิก โดยตำแหน่งแรกเริ่มที่ 0
DOM / event / loop
DOM คือแบบจำลองหน้าเว็บเป็นโครงสร้างที่โปรแกรมอ่านหรือแก้ได้ Event คือเหตุการณ์ เช่น การคลิก และ loop คือคำสั่งทำงานซ้ำ

01 · JavaScript อยู่ตรงไหน?

ทำไมหน้าเว็บแสดงปุ่มได้ แต่กดแล้วไม่คิดคะแนน? การมีปุ่มเป็นเรื่องของโครงสร้าง ส่วนการรับการกดและคำนวณเป็นพฤติกรรม ลองแยกสองงานนี้ก่อนเลือกภาษา Engine คือโปรแกรมประมวลผล JavaScript; API คือช่องทางที่ระบบเปิดให้โค้ดเรียกใช้งาน และ parse คือการอ่านรูปแบบข้อความให้เป็นโครงสร้างที่โปรแกรมทำงานต่อได้

นึกถึงเว็บเป็นโต๊ะอ่านหนังสือ: HTML บอกว่ามีอะไรอยู่บนโต๊ะ CSS จัดให้สวยและอ่านง่าย ส่วน JavaScript ทำให้สิ่งบนโต๊ะตอบสนอง เช่น กดเปิดเฉลยแล้วเห็นคำตอบ หรือเลือกคำตอบแล้วได้คะแนน

เบราว์เซอร์มี JavaScript engine สำหรับรันภาษา และมี Web API อย่าง DOM ให้โค้ดจัดการหน้าเว็บได้ ตัวภาษาไม่ได้เท่ากับ DOM และ JavaScript ก็ทำงานนอกเบราว์เซอร์ได้ด้วย

ส่วน หน้าที่ ตัวอย่างในเว็บนี้
HTML โครงสร้างและเนื้อหา หัวข้อบทเรียนกับปุ่ม Quiz
CSS รูปแบบการแสดงผล สี ฟอนต์ และเลย์เอาต์มือถือ
JavaScript ข้อมูลและพฤติกรรม ตรวจคำตอบและพลิก Flashcard
JAVASCRIPT
<!-- เรียกไฟล์ภายนอก และรอให้ HTML ถูก parse ก่อนทำงาน -->
<script defer src="assets/app.js"></script>

เขียนโค้ดระหว่างแท็ก <script> หรือแยกไฟล์ .js ก็ได้ โดยในไฟล์ .js ไม่ต้องใส่แท็ก script อีก ใช้ console.log() ตรวจค่าระหว่างพัฒนา ส่วนข้อความให้ผู้อ่านเห็นต้องอัปเดต DOM

เป้าหมายบทนี้: อ่านโค้ดแล้วบอกได้ว่า “ค่าอะไรเปลี่ยน” และ “บรรทัดถัดไปคืออะไร”
ปิด JavaScript แล้วหัวข้อยังอยู่ แต่ปุ่มตรวจคะแนนไม่ทำงาน อธิบายได้อย่างไร?

หัวข้ออยู่ใน HTML และยังจัดรูปลักษณ์ด้วย CSS ได้ ส่วนการคำนวณคะแนนต้องให้ JavaScript รับเหตุการณ์แล้วตรวจคำตอบ นี่เป็นเหตุผลที่เว็บควรมีเนื้อหาให้อ่านแม้กิจกรรมใช้งานไม่ได้

02 · ตัวแปรและชนิดข้อมูล

ถ้าสมุดราคาเล่มละ 100 บาท ซื้อ 2 เล่ม โปรแกรมควรเก็บอะไรไว้ก่อนจึงจะคิดยอดได้? เริ่มจาก ราคา และ จำนวน แล้วค่อยหายอดรวม ตัวแปร (variable) คือชื่อที่ใช้เก็บและอ้างถึงข้อมูลระหว่างการทำงาน ตามแนวคิดเรื่องตัวแปรใน Lecture 06 หน้า PDF 26–30

ตัวอย่างสมมตินี้ใช้ let ประกาศชื่อพร้อมค่าเริ่มต้น เครื่องหมาย = อ่านค่าทางขวาแล้วผูกกับชื่อทางซ้าย ส่วน * คือการคูณ คัดลอกโค้ดทั้งชุดไปรันใน Console ของเบราว์เซอร์ได้

let price = 100; // ราคาต่อเล่ม
let quantity = 2; // จำนวนที่ซื้อ
let total = price * quantity; // อ่านค่าทั้งสองแล้วคูณ
console.log(total); // แสดงผลใน Console

ผลใน Console: 200 ไม่ใช่ข้อความที่เพิ่มลงหน้าเว็บ ลำดับคือสร้าง price เป็น 100 สร้าง quantity เป็น 2 คำนวณ 100 × 2 แล้วผูก 200 กับ total สุดท้ายอ่าน total มาแสดง

ลองเปลี่ยนราคา แล้วตามค่าทีละบรรทัด

ทดลองราคา 12.5 และจำนวน 3 สังเกตว่าค่า total จะปรากฏหลังคูณ ส่วน Console จะแสดงหลังบรรทัดสุดท้าย กิจกรรมนี้จำลองเฉพาะโค้ดสี่บรรทัดที่แสดง ไม่ใช่ช่องรันโค้ดอิสระ

  1. let price = 100;
  2. let quantity = 2;
  3. let total = price * quantity;
  4. console.log(total);

ผลใน Console: —

อ่านผลโดยไม่ต้องทดลอง: ราคา 12.5 × จำนวน 3 = 37.5 หากจำนวนเป็น 0 ผลคือ 0 เพราะไม่มีสินค้าที่ซื้อ ชื่อ total เก็บผลตอนที่คูณ ไม่ได้คำนวณใหม่เองเมื่อเราเปลี่ยนตัวแปรภายหลัง

ตัวเลขใช้ชนิด Number ของ JavaScript ซึ่งเป็นเลขฐานสองแบบประมาณค่า บางคู่ เช่น 0.1 × 3 อาจแสดง 0.30000000000000004 กิจกรรมนี้สอนค่าตัวแปร ไม่ใช่ระบบคิดเงินจริงที่ต้องกำหนดวิธีปัดเศษ

ถ้าเพิ่ม quantity เป็น 3 หลังคำนวณ total แล้ว total จะเปลี่ยนเองหรือไม่?

ไม่เปลี่ยน เพราะคำสั่งกำหนดค่าเก็บผลเฉพาะตอนที่บรรทัดนั้นทำงาน ต้องสั่ง total = price * quantity; อีกครั้งจึงจะอ่าน quantity ใหม่ ต่างจากสูตรในตารางคำนวณที่อาจคำนวณอัตโนมัติ

จากตัวอย่างสู่การประกาศและขอบเขต

ตัวแปรคือชื่อที่เราใช้เรียกค่า ประกาศ คือสร้างชื่อ กำหนดค่า คือผูกชื่อกับค่า และ กำหนดค่าเริ่มต้น คือทำทั้งสองอย่างพร้อมกัน เครื่องหมาย = จึงไม่ใช่การถามว่าเท่ากันหรือไม่

JAVASCRIPT
let points;             // ประกาศ: ค่าเริ่มต้นเป็น undefined
points = 10;            // กำหนดค่า
points += 5;            // ตอนนี้ 15
const course = "ITDS241";
console.log(points);    // 15
คำสั่ง ขอบเขต กำหนดใหม่ / ประกาศซ้ำใน scope เดิม
var function หรือ global ได้ / ได้
let block { … } ได้ / ไม่ได้
const block { … } ไม่ได้ / ไม่ได้

เริ่มด้วย const เมื่อไม่ต้องเปลี่ยน binding และใช้ let เมื่อจะกำหนดค่าใหม่ ชื่อตัวแปรแยกตัวพิมพ์เล็ก–ใหญ่ เริ่มด้วยตัวอักษร _ หรือ $ ได้ แต่ห้ามเริ่มด้วยเลขหรือใช้คำสงวนอย่าง class

เลือกชนิดข้อมูลจากสิ่งที่ค่าหมายถึง

100 ที่นำไปคูณเป็น Number (จำนวน) แต่ "100" ที่อยู่ในเครื่องหมายคำพูดเป็น String (ข้อความ) จึงอาจถูกนำไปต่อข้อความแทนการบวก Boolean (ค่าความจริง) มี true และ false ใช้บอกผลของเงื่อนไข ส่วน undefined คือค่าที่ยังไม่ได้กำหนด และ null ใช้แทนความว่างโดยตั้งใจ

Primitive (ค่าพื้นฐาน) คือค่าที่ไม่ใช่ object; ค่านั้นแก้ภายในไม่ได้ แต่ตัวแปร let เปลี่ยนไปอ้างค่าอื่นได้ NaN (Not-a-Number) เป็นค่า Number ที่บอกว่าผลไม่ใช่ตัวเลขที่ใช้คำนวณได้ เช่น Number("hello") คำว่า floating point หมายถึงรูปแบบเก็บจำนวนที่มีความแม่นยำจำกัด

ชนิดข้อมูล ตัวอย่าง จำอย่างไร
Number 42, 3.14, NaN จำนวนทั่วไปและทศนิยมแบบ floating point
String "hello" ข้อความ
Boolean true, false ผลตัดสินใจ
Undefined let x; ยังไม่ได้กำหนดค่า
Null let selected = null ว่างโดยตั้งใจ
Object { name: "Mint" }, [1, 2] ข้อมูลเป็นกลุ่มหรือโครงสร้าง
BigInt / Symbol 42n / Symbol("id") ชนิด primitive เพิ่มเติมของ JavaScript สมัยใหม่

คำถาม · const bag = { count: 1 }; bag.count++; ผิดไหม?

ไม่ผิด count เป็น 2 เพราะแก้ property ของ object เดิม แต่ bag = {} จะผิด เพราะพยายามเปลี่ยน binding ของ const

เมื่อเข้าใจค่าพื้นฐานแล้ว: ชนิดข้อมูลและกรณีพิเศษ

BigInt เก็บจำนวนเต็มที่ใหญ่เกินช่วงปลอดภัยของ Number ส่วน Symbol สร้างค่าเอกลักษณ์ที่ใช้เป็นชื่อ property ได้ รายละเอียดเหล่านี้ช่วยอ่านโค้ดสมัยใหม่ แต่ไม่เปลี่ยนหลักว่าต้องอ่านค่าทางขวาก่อนกำหนดค่าทางซ้าย

JavaScript เป็น dynamically typed: ชนิดผูกกับค่า ไม่ใช่ชื่อ เช่น let x = 1; x = "one"; ทำได้ ส่วน typeof null ได้ "object" เพราะพฤติกรรมเก่าของภาษา ไม่ได้หมายความว่า null เป็น object ปกติ

อย่าสับสนช่วง “จำนวนเต็มที่แทนค่าได้อย่างปลอดภัย” ±(253−1) กับช่วงค่าทั้งหมดของ Number ซึ่งกว้างกว่านั้น แต่ไม่ได้แทนจำนวนเต็มทุกค่าได้แม่นยำ

03 · Object และเครื่องมือพื้นฐาน

ถ้านักศึกษาหนึ่งคนมีทั้งชื่อและคะแนน จะเก็บสองค่านี้ให้รู้ว่าเป็นของคนเดียวกันอย่างไร? Object ทำหน้าที่รวมข้อมูลเป็นชุด การอ้างอิง (reference) คือค่าที่พาเราไปถึงชุดนั้น จึงมีชื่อหลายชื่อที่พาไปถึงข้อมูลชุดเดียวกันได้ ส่วน method คือฟังก์ชันที่เรียกผ่าน object เช่น scores.map(...) ไม่ใช่คำสั่งลึกลับชนิดใหม่

Object รวมข้อมูลที่เกี่ยวข้องไว้ด้วยกัน อ่าน property ด้วยจุด หรือใช้วงเล็บเหลี่ยมเมื่อชื่อมาจากตัวแปร การกำหนด object ให้ตัวแปรอีกตัวจะคัดลอก การอ้างอิง ไม่ได้คัดลอกข้อมูลทั้งก้อน

JAVASCRIPT
const student = { name: "Mint", points: 8 };
const friend = student;
friend.points = 10;
console.log(student.points); // 10: อ้างถึง object เดียวกัน
const key = "name";
console.log(student[key]);   // "Mint"
เครื่องมือ ใช้ทำอะไร ตัวอย่างและผล
Number แปลง/ตรวจตัวเลข parseInt("12.5", 10) → 12; parseFloat("12.5") → 12.5
Math คำนวณโดยไม่ต้อง new Math.round(2.6) → 3; Math.pow(2, 3) → 8
Date เก็บจุดเวลาหนึ่ง new Date(); getDate() = วันในเดือน; getDay() = วันในสัปดาห์ 0–6
String จัดการข้อความ "web tech".split(" ") → ["web", "tech"]
Array รายการเริ่ม index ที่ 0 ["a", "b"][0] → "a"; length → 2

Number.isNaN() ใช้ตรวจค่า NaN; Number.isInteger() ตรวจจำนวนเต็ม การแปลงค่าจากช่อง input จำเป็นเพราะ input.value เป็น string โดยปกติ งานทั่วไปใช้ primitive number/string ได้เลย ไม่จำเป็นต้องห่อด้วย new Number() หรือ new String()

เลือก method ของ Array ให้ตรงคำถาม

Callback คือฟังก์ชันที่ส่งให้ method เรียกกับแต่ละสมาชิก เช่น n => n * 2 รับ n แล้วส่งผลคูณสองกลับ ส่วนการเปลี่ยนข้อมูลเดิมเรียกว่า mutation ตัวอย่างด้านล่างแยกให้เห็นว่า method ใดสร้าง array ใหม่

Method คำถามที่ตอบ เปลี่ยน array เดิมไหม
push / pop เพิ่มท้าย / นำตัวท้ายออก เปลี่ยน
indexOf อยู่ตำแหน่งไหน? indexOf ค้นจากต้น lastIndexOf ค้นจากท้าย ไม่พบคืน −1 ไม่เปลี่ยน
forEach ทำอะไรสักอย่างกับแต่ละตัว ไม่สร้างผลลัพธ์ array; callback อาจแก้ข้อมูลได้
map แต่ละตัวจะกลายเป็นอะไร? คืน array ใหม่
filter เก็บตัวไหนบ้าง? คืน array ใหม่
reduce / reduceRight รวมเป็นผลลัพธ์เดียวจากซ้าย / ขวา ขึ้นกับ callback; ใช้ initial value ให้ชัด
every / some ทุกตัวผ่านไหม / มีอย่างน้อยหนึ่งตัวผ่านไหม คืน Boolean
JAVASCRIPT
const scores = [4, 7, 9];
scores.map(n => n * 2);              // [8, 14, 18]
scores.filter(n => n >= 7);          // [7, 9]
scores.reduce((sum, n) => sum + n, 0); // 20

ตามตัวอย่าง scores = [4, 7, 9] ทีละรอบ: map อ่าน 4 แล้วสร้าง 8, อ่าน 7 แล้วสร้าง 14, อ่าน 9 แล้วสร้าง 18 จึงได้รายการใหม่ ส่วน filter ทดสอบว่าแต่ละค่าถึง 7 หรือไม่ แล้วเก็บ 7 กับ 9 เดิมไว้ สำหรับ reduce เริ่มยอดสะสมที่ 0 แล้วได้ 4 → 11 → 20 คำว่า callback คือฟังก์ชันที่ส่งให้ method เรียกกับแต่ละสมาชิก รูปแบบ n => n * 2 รับ n และส่งค่าคูณสองกลับ จะเรียนการเขียนฟังก์ชันละเอียดใน บท 7

ต้องการรู้ว่ามีคะแนนต่ำกว่า 5 อย่างน้อยหนึ่งค่าหรือไม่ ควรใช้ map หรือ some?

ใช้ scores.some(n => n < 5) ได้ true เพราะ 4 ผ่านเงื่อนไข map จะสร้างรายการผลลัพธ์ต่อสมาชิก จึงตอบคนละคำถาม อย่าตีความ array ที่ไม่ว่างว่าแปลว่าทุกสมาชิกผ่าน

04 · เปรียบเทียบและตัดสินใจ

ถ้าร้านให้ส่วนลดเฉพาะผู้ที่มีคะแนนอย่างน้อย 70 โปรแกรมจะเลือกทางไหน? เราต้องสร้าง expression หรือสิ่งที่ประเมินออกมาเป็นค่า แล้วใช้ผลนั้นเลือกคำสั่ง Operator คือเครื่องหมายที่ทำงานกับค่า และ operand คือค่าที่มันรับ เช่น score >= 70 มีค่าคะแนนกับ 70 เป็น operand คำว่า truthy/falsy หมายถึงค่าที่ถูกมองว่าเป็นจริง/เท็จเมื่อใช้เป็นเงื่อนไข ไม่ได้หมายความว่าค่านั้นมีชนิด Boolean เสมอ

เริ่มจากแยก = (กำหนดค่า), == (เทียบแบบอาจแปลงชนิด) และ === (เทียบโดยไม่แปลงชนิด) ออกจากกัน งานทั่วไปนิยม === เพราะผลคาดเดาง่ายกว่า สำหรับ object การเทียบ === ตรวจว่าอ้างอิงก้อนเดียวกันหรือไม่

Expression ผล เหตุผล
"5" + 2 "52" + ต่อข้อความเมื่อมี string
"5" - 2 3 − แปลง string เป็น number เพื่อคำนวณ
"5" == 5 true มีการแปลงชนิด
"5" === 5 false ชนิดต่างกัน
7 % 3 1 เศษจากการหาร
2 + 3 * 4 14 คูณก่อนบวก; วงเล็บเปลี่ยนลำดับได้

ตัวดำเนินการ ++ และ -- เพิ่ม/ลดหนึ่ง โดย x++ ให้ค่าเดิมก่อนเพิ่ม ส่วน ++x เพิ่มก่อนให้ค่า และ +=, *= คือเขียนย่อของการอ่านค่าเดิมแล้วกำหนดค่าใหม่

&& หยุดเมื่อเจอ falsy ส่วน || หยุดเมื่อเจอ truthy และคืน operand ไม่จำเป็นต้องคืน Boolean; ! กลับค่าความจริง ค่าที่พบบ่อยว่า falsy คือ false, 0, "", null, undefined, NaN แต่ [] และ {} เป็น truthy

JAVASCRIPT
const score = 72;
let grade;
if (score >= 80) {
  grade = "A";
} else if (score >= 70) {
  grade = "B";
} else {
  grade = "ทบทวนเพิ่ม";
}
const passed = score >= 50 ? "ผ่าน" : "ทบทวน";
// ตัวอย่างนี้สมมติ score เป็นตัวเลขในช่วง 0–100

if / else if / else เลือกแขนงแรกที่เงื่อนไขเป็นจริง ส่วน ternary condition ? yes : no เหมาะกับการเลือกค่าสั้น ๆ switch เลือก case ที่ตรงแบบ strict equality; หากไม่มี break อาจทำ case ถัดไปต่อ (fall-through) และใช้ default เมื่อไม่พบ case

คำถาม · let x = 2; const y = x++; หลังสองคำสั่งนี้ x และ y เป็นเท่าไร?

x = 3 และ y = 2 เพราะ postfix ให้ค่าเดิมกับ y ก่อนเพิ่ม x

อ่านตัวอย่างคะแนน 72 ตามทางเดิน: 72 ≥ 80 เป็นเท็จ จึงข้ามการให้ A; 72 ≥ 70 เป็นจริง จึงกำหนด B แล้วออกจากชุด if โดยไม่เข้า else หากสลับให้ตรวจ ≥ 50 ก่อน ≥ 80 ผู้ได้ 90 จะเข้าทาง ≥ 50 ก่อนด้วย ลำดับเงื่อนไขจึงมีผล

const score = 72;
let grade;
if (score >= 80) grade = "A";
else if (score >= 70) grade = "B";
else grade = "ทบทวนเพิ่ม";
console.log(grade);
ลองแก้ score เป็น 70 และ 69 ผลต่างกันตรงไหน?

70 ได้ B เพราะรวมขอบเขตด้วย ≥ ส่วน 69 เข้า else ได้ “ทบทวนเพิ่ม” การทดสอบค่าตรงขอบเขตช่วยพบข้อผิดพลาดจากการเขียน > แทน ≥

05 · มองเห็น loop ทีละขั้น

ถ้าจะบวก 1 ถึง 100 เราไม่ควรเขียนคำสั่งบวกหนึ่งร้อยบรรทัด แต่ต้องอธิบายกฎว่ารอบถัดไปต่างจากรอบนี้อย่างไร Body คือคำสั่งภายในรอบ Counter คือตัวนับ และ sentinel คือค่าพิเศษที่ตกลงให้หมายถึงจบ เช่นข้อความ "stop" ส่วน infinite loop คือการวนที่ไม่มีทางถึงเงื่อนไขหยุด

Loop คือการกลับมาทำงานเดิมเมื่อเงื่อนไขยังผ่าน ตรวจให้ครบสามอย่าง: เริ่มที่ไหน → ตรวจอะไร → เปลี่ยนค่าอย่างไรให้หยุดได้ การลืมอัปเดตค่าที่ใช้ตรวจอาจทำให้เกิด infinite loop

โครงสร้าง ตรวจเมื่อไร เหมาะกับ
for ก่อนเข้า body แต่ละรอบ มีตัวนับหรือรู้ช่วงที่จะวน
while ก่อนเข้า body แต่ละรอบ ยังไม่รู้จำนวนครั้ง รอเงื่อนไขหรือ sentinel
do…while หลัง body ต้องทำอย่างน้อยหนึ่งครั้ง
JAVASCRIPT
const limit = 3;
let sum = 0;
for (let i = 1; i <= limit; i++) {
  sum += i;
}
// ลำดับ: เริ่มตัวนับ → ตรวจ → บวก → เพิ่มตัวนับ → กลับไปตรวจ

Loop lab · ผลรวม 1 ถึง n

กดทีละขั้นแล้วสังเกตว่า i เพิ่มเมื่อไร และ sum เปลี่ยนตรงไหน

เริ่มตรวจบวกi++จบ
i 1
sum 0

คำสั่งที่เปลี่ยนทางเดิน

  • break ออกจาก loop ที่ใกล้ที่สุด; continue ข้ามส่วนที่เหลือของรอบนั้น ใน for จะยังไปทำตัวเพิ่มก่อนตรวจรอบใหม่
  • Counter-controlled ใช้ตัวนับ; sentinel-controlled ใช้ค่าพิเศษ เช่น "stop"; loop ซ้อนใช้ตัวนับคนละตัวเพื่อไม่ชนกัน
  • Label เป็นชื่อกำกับ statement ใช้ break ออกไปยังบล็อกที่มีชื่อ หรือ continue ไปยัง loop ที่มีชื่อนั้น ไม่ใช่คำสั่งกระโดดไปที่ใดก็ได้
  • for…in วนชื่อ property ที่ enumerable รวม inherited properties; for…of วนค่าของ iterable เช่น Array (เจาะลึกในบท 8)

คำถาม · ทำไม loop 1 ถึง 3 จบด้วย i = 4 แต่ sum = 6?

หลังบวก 3 แล้ว i++ ทำให้ตัวนับเป็น 4 จากนั้นเงื่อนไข 4 <= 3 เป็น false จึงออกโดยไม่บวก 4 อีก หมายเหตุ: i ที่ประกาศด้วย let ใน for จะอ่านไม่ได้จากนอก loop; lab แสดงสถานะภายในเพื่อการเรียนรู้

อ่านผลโดยไม่ใช้กิจกรรม: n = 3 มีรอบบวกสามครั้ง (i, sum) เป็น (1,1), (2,3), (3,6) แล้วตรวจ i = 4 ไม่ผ่าน ไม่ได้บวก 4 เข้าไป ส่วน n = 5 ได้ผลสะสม 1, 3, 6, 10, 15 ลองกดเริ่มใหม่แล้วทำนาย sum ก่อนกด “ขั้นถัดไป” ทุกครั้ง

const limit = 3;
let sum = 0;
for (let i = 1; i <= limit; i++) {
  sum += i;
}
console.log(sum);
ถ้าแก้เงื่อนไขเป็น i < limit โดย limit = 3 จะได้เท่าไร?

ได้ 3 เพราะบวกแค่ 1 กับ 2 นี่คือข้อผิดพลาดขาดปลายช่วงหนึ่งค่า ถ้าต้องรวม limit ต้องใช้ ≤ ส่วนตัวแปร i ที่ประกาศด้วย let ใน for ไม่ได้อ่านจากภายนอก loop ได้โดยอัตโนมัติ ค่าที่กิจกรรมแสดงเป็นบันทึกแต่ละขั้น

06 · เชื่อมทุกอย่างด้วย Tic-tac-toe

ถ้าคลิกช่องเดิมสองครั้งแล้วระบบสลับผู้เล่นสองครั้ง เกมจะผิดแม้หน้าตาดูเหมือนเดิม เราจึงต้องให้ state หรือข้อมูลสถานะเป็นตัวตัดสินว่าเดินได้หรือไม่ ก่อนปรับ UI (User Interface) หรือส่วนที่ผู้ใช้เห็นและใช้งาน เกมนี้ต่อยอด array เงื่อนไข และ loop จากหัวข้อก่อนหน้า

เกมในสไลด์เป็นตัวอย่างว่า UI และข้อมูลต้องไปด้วยกัน ใช้ array เก็บกระดาน ใช้ตัวแปรเก็บผู้เล่นปัจจุบัน และตรวจรูปแบบชนะ 8 แบบหลังเดินแต่ละครั้ง ลำดับสำคัญคือ ตรวจชนะก่อนตรวจเสมอ เพราะตาสุดท้ายอาจเต็มกระดานและชนะพร้อมกัน

รับ clickตรวจช่องว่างแก้ stateตรวจจบเกมอัปเดต UI

ลองเล่น แล้วอ่านทางเดินของโค้ด

ตาของ X

คลิกช่องว่างเพื่อเริ่ม แล้วติดตามค่าที่เปลี่ยน

ก่อนสอบ ลองอธิบายได้ว่า: ทำไมต้องห้ามลงช่องเดิม? ทำไมต้องหยุดรับ click เมื่อชนะ? และ restart ต้องรีเซ็ตข้อมูลใดบ้าง?

ลองเส้นทางชนะโดยนับช่องซ้ายไปขวา บนลงล่างเป็น 1–9: X ลง 1, O ลง 4, X ลง 2, O ลง 5, X ลง 3 จบด้วย X ชนะ แถวแรกมี X ทั้งสามช่อง หลังจบลองกดช่อง 9 กระดานต้องไม่เปลี่ยน แล้วกดเริ่มเกมใหม่ ข้อมูลทั้ง 9 ช่องต้องว่าง ผู้เล่นกลับเป็น X และสถานะจบเกมกลับเป็นยังไม่จบ

ถ้ากระดานเต็มในตาเดียวกับที่ผู้เล่นเรียงครบสามช่อง ต้องแสดงชนะหรือเสมอ?

ชนะ จึงต้องตรวจรูปแบบชนะก่อนตรวจว่าทุกช่องเต็ม ถ้าตรวจเต็มก่อนจะประกาศเสมอผิด การจำลำดับคลิกไม่สำคัญเท่าการอธิบายเงื่อนไขและลำดับตรวจ

เราเริ่มจากชื่อที่ผูกกับค่า ใช้ตัวดำเนินการคำนวณและเปรียบเทียบ แล้วใช้เงื่อนไขเลือกทางเดินและ loop ทำซ้ำ Object และ Array ช่วยเก็บข้อมูลที่สัมพันธ์กัน เกมท้ายบทจึงเป็นการเปลี่ยนข้อมูลตามการคลิกแล้วตรวจเงื่อนไขชนะ ไม่ใช่โค้ดลึกลับอีกชุดหนึ่ง เมื่ออ่านโค้ด ให้ถามว่าบรรทัดนี้อ่านค่าใด เปลี่ยนค่าใด และบรรทัดต่อไปคืออะไร บท 7 จะรวมคำสั่งเหล่านี้เป็นฟังก์ชันที่เรียกใช้ซ้ำได้
