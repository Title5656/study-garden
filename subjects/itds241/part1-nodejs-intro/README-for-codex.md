## ข้อห้ามด้านลิขสิทธิ์ (สำคัญ)
- **ห้ามใส่ภาพสไลด์ (ทั้งสไลด์หรือ screenshot) ลงเว็บ** เนื้อหาทั้งหมดเขียนใหม่เป็นสรุปแล้ว
- ไดอะแกรมทุกอัน (request/response, event loop, URL components, flow ฟอร์ม ฯลฯ) ให้ **วาดใหม่เป็น SVG/HTML/CSS** เอง ห้ามดึงรูปจาก PDF
- โค้ดตัวอย่างเป็นโค้ดสั้นแบบสอนทั่วไป ใช้ได้ตามที่เขียนไว้

## Syntax ที่ใช้ในไฟล์ content.md
| Block | ความหมาย |
|---|---|
| `:::interactive{id="..." component="..."}` ... `:::` | ให้สร้าง interactive object ตามคำอธิบายข้างใน |
| `:::quiz{id="..."}` ... `:::` | ข้อสอบท้ายบท: `Q`, ตัวเลือก, `Answer`, `Why` → ทำเป็นควิซกดตอบแล้วเฉลยทีละข้อ |
| `:::exam-tip` ... `:::` | กล่องเน้น "ต้องจำ/จุดที่มักสับสน" |
| `:::note` ... `:::` | หมายเหตุ/ข้อสังเกตเพิ่มเติม (เช่น สไลด์พิมพ์ผิด) |

## Component ที่ควรสร้างเป็น reusable
- `Quiz` — ปุ่มเลือกคำตอบ + เฉลย + เก็บคะแนน
- `CodeTrace` — ไล่โค้ดทีละบรรทัด แสดงค่าตัวแปร/เอาต์พุตแต่ละสเต็ป
- `Stepper` — ขั้นตอนทีละสเต็ป (ปุ่มถัดไป/ย้อน)
- `Flashcards` — การ์ดพลิก (คำศัพท์ → ความหมาย)
- `DragMatch` — ลากจับคู่
- `LiveTyper` — ช่องให้พิมพ์โค้ด/ค่าแล้วดูผลจำลองทันที (ไม่ต้องรัน Node จริง ใช้ JS ฝั่ง browser จำลองเอา)
- ตัวจำลองเฉพาะเรื่อง: `RequestResponseSim`, `EventLoopSim`, `UrlExplorer`, `PathParser`, `AsyncOrderSim`, `RouteTester`, `FormSimulator` (รายละเอียดอยู่ในแต่ละ block)

## หลักการเขียนที่ใช้
- เรียงตามลำดับสไลด์ต้นฉบับ แยกเป็นบท (Chapter)
- สำหรับคนไม่เคยเรียน: อธิบายศัพท์ก่อนใช้ มีภาพเปรียบเทียบ
- ทุกบทจบด้วย: สรุปจุดต้องจำ → จุดที่มักสับสน → ข้อสอบพร้อมเฉลย
- ส่วนที่ผมเพิ่มเองนอกสไลด์ติดป้าย "เสริมความเข้าใจ" ไว้ชัดเจน
