01 / บท 1 · PDF หน้า 4–8

เทอร์โมไดนามิกส์ศึกษาสิ่งใด

อุณหพลศาสตร์ (Thermodynamics) ศึกษาพลังงาน การเปลี่ยนรูปพลังงาน และการเปลี่ยนสถานะของสารในระดับมหภาค เราใช้มันตอบว่า “กระบวนการใช้พลังงานเท่าไร” “เกิดขึ้นได้หรือไม่” และ “มีประสิทธิภาพสูงสุดเท่าไร” กฎข้อที่หนึ่ง บอกว่าพลังงานคงอยู่ ส่วน กฎข้อที่สอง กำหนดทิศทางและขีดจำกัดของการเปลี่ยนพลังงาน

แขนงที่เกี่ยวข้องมี Technical Thermodynamics (อุปกรณ์และการแปลงพลังงาน), Pure-component Thermodynamics (สมบัติสารบริสุทธิ์), Mixture Thermodynamics (สารผสมและสมดุลเฟส), Statistical Thermodynamics (ความเชื่อมโยงกับโมเลกุล), และ Non-equilibrium Thermodynamics (การขนส่งความร้อนและมวลที่ยังไม่สมดุล) เนื้อหาในวิชานี้เน้นสมดุลและการประยุกต์กับกระบวนการเคมี

บริบททางประวัติศาสตร์: กฎ Boyle งานของ Carnot เรื่องเครื่องยนต์ความร้อน Mayer เรื่องอนุรักษ์พลังงาน Clausius เรื่องเอนโทรปี และ Kelvin เรื่องสเกลอุณหภูมิ เป็นหมุดหมายสำคัญ ชื่อของนักวิทยาศาสตร์บอกที่มาของแนวคิด ไม่ใช่กฎแยกให้ท่อง

ระบบ ขอบเขต เฟส และองค์ประกอบ

System คือส่วนที่เลือกศึกษา Surroundings คือสิ่งรอบนอก และ Boundary คือเส้นแบ่งที่อาจอยู่กับที่หรือเคลื่อนที่ได้ การเลือกขอบเขตให้ถูกเป็นขั้นแรกก่อนตั้งสมการ

ชนิดระบบมวลผ่านขอบเขต?พลังงานผ่านได้?ตัวอย่าง
เปิด (Open)ได้ได้คอมเพรสเซอร์ ท่อ กังหัน
ปิด (Closed)ไม่ได้ได้ก๊าซในกระบอกสูบปิดสนิท
โดดเดี่ยว (Isolated)ไม่ได้ไม่ได้ระบบอุดมคติที่ไม่แลกเปลี่ยนใด ๆ

Component คือชนิดสารเคมี เช่น H₂O, CO₂; Phase คือส่วนที่มีสมบัติสม่ำเสมอ เช่น น้ำแข็ง น้ำเหลว และไอน้ำเป็น 3 เฟสขององค์ประกอบเดียวกัน ส่วน “element” คือธาตุทางเคมี จึงต่างจากองค์ประกอบในเชิงการนับชนิดสารในระบบ

ระบบอยู่ใน Thermodynamic Equilibrium เมื่อสมบัติมหภาคไม่เปลี่ยนตามเวลาและไม่มีแรงขับให้เกิดการเปลี่ยนแปลงภายใน (สมดุลความร้อน กล สมดุลเฟส/เคมีตามกรณี) การนิ่งชั่วคราวไม่ได้ยืนยันว่าสมดุลครบทุกด้าน

03 / บท 1 · PDF หน้า 16–20

ตัวแปรสถานะ Intensive และ Extensive

State คือสภาวะที่กำหนดด้วยสมบัติ เช่น P, T, V, U, H, S; Equation of State (EoS) เชื่อม P–V–T ตัวอย่างก๊าซอุดมคติ PV = nRT โดย n เป็นจำนวนโมล

สมบัติ Intensive ไม่ขึ้นกับปริมาณทั้งหมด เช่น T, P, ความหนาแน่น ρ และ specific volume v; Extensive แปรตามขนาดระบบ เช่น มวล m, ปริมาตร V, พลังงาน U, เอนทัลปี H และเอนโทรปี S หากรวมระบบสองชุดที่เหมือนกัน extensive เพิ่มสองเท่า แต่ intensive ยังเท่าเดิมเมื่อสภาวะเหมือนเดิม

สมบัติจำเพาะต่อมวล: u = U/m, h = H/m, s = S/m, v = V/m ส่วนสมบัติโมลาร์ใช้หารด้วย n อย่าสลับหน่วย J, kJ, mol, kg ในสูตรเดียวกัน

คู่ตัวแปร Conjugate ที่พบคือ P–V, T–S, และศักย์เคมี μ–จำนวนอนุภาค N ความหมายคือผลคูณ/เทอมอนุพันธ์ของคู่นี้สัมพันธ์กับการเปลี่ยนพลังงานของระบบ

04 / บท 1 · PDF หน้า 21–24

ชนิดกระบวนการและกฎข้อศูนย์

กระบวนการเปลี่ยนระบบจากสถานะ 1 ไป 2 โดยเส้นทางระหว่างทางอาจต่างกัน: Isobaric ความดันคงที่, Isochoric ปริมาตรคงที่, Isothermal อุณหภูมิคงที่, Adiabatic ไม่ถ่ายเทความร้อน (Q=0), Isentropic เอนโทรปีคงที่ ซึ่งมักต้องทั้ง adiabatic และ reversible ในระบบอย่างง่าย

การขยายตัว (Expansion) และอัดตัว (Compression) เปลี่ยนปริมาตรในทิศทางตรงข้าม Quasistatic คือดำเนินช้าพอให้สภาวะภายในใกล้สมดุล แต่ยังไม่รับประกันว่า reversible เพราะอาจมีแรงเสียดทานหรือการถ่ายเทข้าม ΔT

Zeroth Law: ถ้า A สมดุลความร้อนกับ B และ B กับ C แล้ว A กับ C จะสมดุลความร้อนกัน ทำให้เรานิยามอุณหภูมิและใช้เทอร์โมมิเตอร์ได้ กฎที่หนึ่งอนุรักษ์พลังงาน กฎที่สองบอกว่าเอนโทรปีรวมของระบบโดดเดี่ยวไม่ลดลง กฎที่สามให้จุดอ้างอิงเอนโทรปีของผลึกสมบูรณ์ที่ 0 K

05 / บท 1 · PDF หน้า 25–36

เครื่องมือคณิตศาสตร์และหน่วยที่ต้องรู้

เมื่อสมบัติขึ้นกับสองตัวแปร เช่น U(S,V), อนุพันธ์ย่อย หมายถึงเปลี่ยนตัวหนึ่งโดยตรึงอีกตัว: dU = (∂U/∂S)ᵥ dS + (∂U/∂V)ₛ dV ถ้าเป็น Simple Compressible System แบบองค์ประกอบคงที่ dU = T dS − P dV และจาก H = U + PV ได้ dH = T dS + V dP เมื่ออยู่บนเส้นทางสมดุลที่เหมาะสม สมการพื้นฐานเชื่อมสมบัติสถานะ ไม่ได้บอกว่ากระบวนการจริงย้อนกลับได้ทุกกรณี

อุณหภูมิสัมบูรณ์: T[K] = t[°C] + 273.15; t[°F] = (9/5)t[°C] + 32; T[°R] = (9/5)T[K] ความดันคือแรงต่อพื้นที่ P = F/A และ Pabs = Pgauge + Patm ห้ามนำ °C มาแทน K ในอัตราส่วนอุณหภูมิหรือสมการก๊าซอุดมคติ

เครื่องมือทดลองในสไลด์ประกอบด้วยเครื่องวัดความดันคอลัมน์ปรอท กฎ Boyle กราฟ P–V และ gas thermometer: สิ่งเหล่านี้เชื่อมค่าที่วัดได้กับ P, V, T โดยต้องคำนึงถึงแรงดันอ้างอิงและหน่วย

06 / บท 1 · PDF หน้า 37–45

ความร้อน งาน และพลังงานภายใน

Heat (Q) คือพลังงานที่ข้ามขอบเขตเพราะความต่างอุณหภูมิ ไม่ใช่สารหรือปริมาณ “ความร้อนที่สะสมในวัตถุ” ส่วน Work (W) คือการส่งผ่านพลังงานผ่านแรงกับระยะทางหรือกลไกอื่น (งานไฟฟ้า เพลา ยกวัตถุ อัดก๊าซ) ทั้ง Q และ W ขึ้นกับเส้นทาง

พลังงานรวม E = U + KE + PE โดย KE = ½mu² และ PE = mgz ในระบบนิ่ง KE/PE อาจเล็กจนละได้ แต่ต้องตรวจสมมติฐานก่อน

เว็บนี้ใช้เครื่องหมายมาตรฐานวิศวกรรม Q บวก = ความร้อนเข้าสู่ระบบ, Wout บวก = งานที่ระบบทำออก ดังนั้น ΔU = Q − Wout สำหรับระบบปิดที่ไม่มี ΔKE/ΔPE; ในสไลด์ผู้สอนใช้ A หรือ Won บวก = งานที่กระทำต่อระบบ จึงเขียน ΔU = Q + Won ทั้งสองเทียบเท่าเมื่อ Won = −Wout

07 / บท 1 · PDF หน้า 46–57

State function งาน P–V และเอนทัลปี

State Function เช่น U, H, S ขึ้นกับสถานะต้นและปลาย ทำให้ ΔU เท่ากันไม่ว่าจะใช้เส้นทางใด แต่ Heat/Work เป็น Path Function จึงเขียน δQ, δW แทน dQ, dW แบบ exact differential

สำหรับกระบวนการ Quasistatic แบบที่มีแต่งาน P–V: δWout = Pext dV และถ้าย้อนกลับได้ทางกล Wout,rev = ∫ P dV; กราฟ P–V พื้นที่ใต้เส้นคือขนาดงาน (เมื่อหน่วยสอดคล้อง) ปริมาตรคงที่ทำให้งานขอบเขตเป็นศูนย์

นิยามเอนทัลปี H = U + PV ทำให้อธิบายระบบที่มีการไหลเข้า–ออกสะดวก; สำหรับระบบปิดที่มีเฉพาะงาน P–V และแรงดันคงที่ Qp = ΔH ถ้าปริมาตรคงที่ Qv = ΔU ภายใต้สมมติฐานที่ระบุ

Heat capacity: Cv = (∂U/∂T)ᵥ, Cp = (∂H/∂T)ₚ; สำหรับก๊าซอุดมคติ Cp − Cv = R แบบต่อโมล (หรือใช้ R จำเพาะต่อมวลเมื่อใช้ค่าแบบต่อ kg) ทั้ง U และ H ของก๊าซอุดมคติขึ้นกับ T เท่านั้น ไม่ใช่กฎทั่วไปของของไหลจริง

08 / บท 1 · PDF หน้า 58–61

กฎข้อสองและสามก่อนเข้าบทลึก

กฎข้อสองกล่าวว่า ความร้อนไม่ไหลจากเย็นไปหาร้อนเองโดยไม่มีผลอื่น และเครื่องจักรวัฏจักรไม่สามารถแปลงความร้อนจากแหล่งเดียวเป็นงานทั้งหมด Entropy S ช่วยบอกความไม่ผันกลับ: dS ≥ δQ/Tboundary สำหรับระบบปิดโดยมีเงื่อนไขที่เกี่ยวข้อง และ Sgen ≥ 0 ความเท่ากันใช้กับกระบวนการที่ย้อนกลับได้

กฎข้อสามกำหนดเอนโทรปีของผลึกสมบูรณ์ในสถานะพื้นต่ำสุดที่ 0 K เป็นศูนย์ ทำให้มีสเกล Absolute entropy; บางสารเกิด Residual entropy จากโครงสร้างไม่เป็นระเบียบ จึงอย่าตีความว่าทุกตัวอย่างทดลองที่ 0 K มี S=0

สูตรสำหรับ Closed System ย้อนกลับได้: dU = T dS − P dV ใช้เป็นสะพานเชื่อมสู่บท 2, 5 และ 6; ไม่ใช่สูตรทดแทนสมดุลพลังงานเมื่อมีแรงเสียดทานโดยไม่มีการพิจารณาเอนโทรปีเกิดขึ้น

ทดลองปรับค่าด้วยตัวเอง

เลื่อนปริมาตรแล้วดูความดันที่เปลี่ยน เมื่อ T และ n คงที่ เครื่องมือนี้เป็นแบบจำลองภายใต้สมมติฐานที่ระบุ ไม่ใช่โปรแกรมออกแบบโรงงาน

ตัวอย่างคำนวณทีละขั้น

คำนวณความดันก๊าซจากสมการ PV=nRT

ก๊าซอุดมคติ n=1 mol, T=300 K, V=10 L จงหา P

  1. ตรวจระบบ: ก๊าซอุดมคติที่สมดุลและ T เป็น K ใช้ R=8.314 kPa·L/(mol·K)
  2. จัดสมการ P=nRT/V = 1×8.314×300/10 = 249.42 kPa
  3. ตรวจหน่วย mol×(kPa·L/mol·K)×K/L = kPa; ถ้า V เพิ่มสองเท่าที่ T,n คงที่ ความดันเหลือครึ่งเดียว

โจทย์ตัวเลขตัวอย่างนี้สร้างใหม่เพื่อฝึกวิธีคิด ไม่ใช่ข้อความหรือเฉลยคัดลอกจากเอกสารผู้สอน

แผนที่โจทย์จากสไลด์

ตารางนี้ชี้โจทย์ที่มีในเอกสารและหลักการที่ต้องใช้แก้ เพื่อกลับไปฝึกแทนตัวเลขจากสไลด์ ไม่ได้คัดลอกโจทย์ยาวหรือรับรองผลเฉลยอาจารย์

คำอธิบายเพิ่มเติมช่วยแยกขอบเขตสมมติฐาน ความคลาดเคลื่อนของการประมาณ หน่วย เครื่องหมาย และกรณีสูตรใช้ไม่ได้ สูตรหรือสมการที่ต้องใช้ข้อมูลเฉพาะสารควรตรวจจากตารางสมบัติ/สมการในสไลด์ต้นฉบับอีกครั้ง

ขอบเขตการสรุป: ครอบคลุมหัวข้อหลัก สูตรและตัวอย่างชนิดต่าง ๆ ในบทนี้ แต่ไม่ได้แทนการดูภาพสไลด์ทุกหน้า หรือขั้นตอนคำนวณเชิงตัวเลขทุกบรรทัดของตัวอย่าง 292 หน้า เอกสารต้นฉบับไม่ได้คัดลอกไปยัง repository สาธารณะเพื่อรักษาสิทธิ์ผู้จัดทำ
